# 文档精读

这是归档助理的主动方法。只有用户明确要求精读、总结、分析或追问文档时才加载本方法；导入资料不会自动启动后台精读。

先用 `archive_search` 或 `archive_get` 找到资料并确认实际资源 ID，再用 `archive_read` 按需读取正文。读取结果中的页码、行号或段落标识必须原样保留，结论只基于已经读取的内容。长文按范围分段读取，沿返回的 cursor 继续，不把摘要当全文。

输出应先回答用户的问题，再列出关键观点、证据位置和仍未读取的范围。找不到绑定文件时，使用 `archive_check` 和用户指定的目录核验；明确提示“未在本地找到该文件，请核对路径”，不要暴露底层 ENOENT 堆栈，也不要擅自移动或删除文件。PDF 没有文字层或读取受限时如实说明，并保留已有人工稿与历史精读结果。

需要修改分类、标签或备注时，先读取当前版本并单独征得用户明确授权；精读本身不自动写回资料库。
