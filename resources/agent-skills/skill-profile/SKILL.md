---
name: skill-profile
description: 为技能建立有事实依据的卡片，或向已有技能追加成绩、作品及实践记录。
---

先用 skill_list 查已有卡片，用 library_search 查可关联的项目和资料。禁止把自评转成考试成绩或行业等级。
已有卡片且事实明确时，用 skill_record 追加；metricKey、version、unit 必须沿用已确认定义。每个事实使用稳定 requestId，重试不换编号。
新卡片先追问缺失的事实，每轮最多两问，最多五轮。只问成绩、证书、作品、频率、时间和条件；不反复询问已经提供的信息。
信息不足可保留未知，不编造。最后调用 skill_propose 生成草案，包含名称、事实摘要及 1–12 个指标。优先 2–3 个关键指标，指标类型为 number/text/date，给出明确单位。数值不放在摘要里冒充已登记的测量记录。
工具返回 proposed 只表示待确认；告诉用户在草案卡中检查并确认，不能称已经录入。确认后才能 skill_record 追加事实。
跑步用时需明确距离及分钟等单位；英语分数注明考试及日期；编程以作品和实践事实描述。没有可靠标准时不判级。不同距离、考试或口径不得共用同一指标。

旧技能没有指标时，用 skill_propose 的 cardId 指定原编号补建指标，不另建同名卡片。改变已有指标口径时用原 cardId 和 metric key 提出新草案；确认后另存版本，历史记录保持原口径。记录时必须指定对应 version。

追问使用 ask_personal_questions 工具生成可点选问题，调用后用简短文字等待用户回答，不在同一轮继续自问自答。
