## 已整合的功能

| 工作包 | 本次实现 |
| --- | --- |
| W1 | 游戏身份与封面关键词独立；本地、官方和 Steam 候选缓存；预览解码；失败保留原图；缺失缓存可恢复；无 AI 手动注册 |
| W2 | 稳定作品/内容/来源身份、受管理目录和文件资产；历史记录、多个版本及共享文件关联 |
| W3 | 作品子目录与资源包发布；清单、简介、封面缺项记录；避免覆盖现有资源 |
| W4 | 下载、资源包、本地扫描共用注册边界；离线导入；重复注册与阶段重试 |
| W5 | 作品首页、内容优先详情、版本选择、文件检查与定位、统一下载面板 |
| W6 | 链接草稿、串行下载队列、持久任务、失败阶段重试、扫描结果与配置入口 |
| W7 | 整理预览、逻辑合并、保留原件的物理整理、逐项结果、重试/回退、目录重新定位及完整元数据备份恢复 |

主会话补齐了整理、任务和备份的 IPC/preload/类型接线，并修复了以下跨模块问题：

- Vue 代理对象不能穿过 Electron context bridge，导致任务保存报错。任务现在保存为可克隆的普通数据，并处理同步与异步保存失败。
- 显式整理后的旧作品 ID、来源、原目录和文件继续指向保留作品；重扫不再拆分已合并作品，也不会重置嵌套资料库的根目录。
- 物理整理后重新导入保留的原件，会复用已发布的文件身份，避免重复增加版本；保留用户资料和观看进度。
- 清空资料库同时清理数据库、主进程下载缓存和渲染进程状态；定向任务清理不会移除运行中的任务，空 ID 列表不执行清理。
- 整理预览按季/集编号显示。成功操作会消耗旧预览，结果页不再同时显示“已完成”和“请重新预览”。

JSON 备份覆盖 **21 张元数据表**，包括软件、游戏、影视、内容、来源/资产关联、观看与任务历史、整理记录。它不打包媒体、游戏程序或图片二进制，也不包含 API 配置。恢复先完整验证和预览，经原生确认后用 `VACUUM INTO` 保存包含 WAL 数据的当前数据库快照，再原子恢复并请求立即重启。快照位于相应 profile 的 `recovery` 目录。
