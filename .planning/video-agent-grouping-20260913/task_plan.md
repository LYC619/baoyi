# Agent 整理批量失败修复

用户在上一版选择 137 部作品生成整理预览，得到“Agent 没有提交可用分组”。延续已授权的视频整理功能修复；主会话串行实现、审查、验证，不操作正式视频或正式资料库，不覆盖正在运行的程序包。

## 已确认

- 正在运行 0.8.0-video-import-preview-20260913；正式任务记录只有开始和失败，未记录模型文本、工具拒绝理由或停止原因，不能还原这一次的具体模型答复。
- 当前 MiniMaxAI/MiniMax-M3 在两个中性样例上正常调用工具；已用现有配置做一次小样本检查，未发送真实片名或路径。
- 正式库只读统计为 137 部，含 9 个已有多集合集；109 个标题可解析集数，29 组有共同系列前缀。现实现将所有作品一次性发送，任一分组校验失败都会抛弃整次工具调用，且只允许 4 轮。

## 修复设计

- 先按一致片名和集号找可合并的单集候选，把同系列放在相邻批次，限制每批作品数；原选择中的其他作品仍可补封面或补资料。
- 模型使用简短引用；只接受本批已选作品。每组独立校验并保留有效建议，不让一个错误拖垮全批。空分组、失败分组与模型未提交结果分开显示。
- 整理专用请求明确要求工具调用，首次有效提交后结束；兼容严格 JSON 文本返回，仍走同一身份/片名/集数校验。
- 模型文本、工具结果和停止原因进入分析日志与任务日志；失败批次给出具体提示，可保留其他批次的建议并继续补图。
- 继续要求预览确认后才更改资料或文件；不对已有作品执行自动合并。
