# Security / 安全问题

Please do not post API keys, account tokens, private profiles or exploitable personal-data examples in a public issue.

If GitHub's **Security → Report a vulnerability** option is available in this repository, use it for a private report. If it is unavailable, open a minimal issue asking the maintainer for a private reporting channel; include no exploit details or personal data. No security email address is assumed.

Include the affected version, prerequisites, impact and a synthetic reproduction. This is a personal open-source project; no guaranteed response time or fixed security-support window is promised. Check the current release notes for fixes before installing an update.

报告安全问题时优先使用仓库提供的私密漏洞报告入口。如果尚未启用，只发不含漏洞细节和个人数据的简短问题，请维护者提供私密联系渠道。不要上传日常资料库或凭据；尽量使用虚构样例说明影响和复现条件。
