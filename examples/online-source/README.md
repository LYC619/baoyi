# 在线来源本机演示

启动 `node examples/online-source/serve.cjs`，保持窗口打开。在抱一「影视 → 找视频」输入 `http://127.0.0.1:18765/index.html`，点击「接入海报墙」。不需要导入 JSON。

首页有六部作品，点击作品读取详情；「观看」在主窗口播放程序生成的 WebM，「下载保存」使用原有任务和入库流程。下一页新增两部作品，其中「只有观看页面」演示没有直接媒体文件时的提示。`/unsupported.html` 演示未适配网页。

所有图片和短片由隔离界面测试生成，不访问外站。不同标题使用同一段测试短片。固定端口 18765 用于重启后继续读取原来源；如端口被占用，先关闭之前的演示服务。

独立预览位于 `release/online-source-preview`，其中 `start-demo.cmd` 使用预览自带运行时启动服务，无需安装 Node；`start-preview.cmd` 使用独立资料目录启动抱一。下载时请检查保存目录，选择用于试用的文件夹。
