# 本机海报墙示例

`catalogue.json` 可直接导入查看作品墙，不包含外部地址。`assets/` 中的海报和短视频由界面验收脚本生成，不含外部影片。

要体验完整的观看与保存：

1. 在项目目录执行 `node examples/video-discovery/serve.cjs`。预览包也提供“启动本机演示.cmd”，不需要另装 Node。
2. 保持演示窗口打开，进入抱一“影视库 → 找视频 → 导入来源目录”。
3. 选择示例目录中刚生成的 `localhost-catalogue.json`。
4. 点击海报、观看、保存，按需选择保存位置和是否加入本地库。

服务仅监听 `127.0.0.1`。六个演示作品使用同一段短视频，只验证操作流程。每次启动会换一个本机端口，需要重新导入生成的目录；个人标记仍保留。

预览包中的“启动隔离预览.cmd”使用独立资料目录；直接打开 exe 则按程序默认规则使用资料目录。
