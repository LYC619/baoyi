# 批量导入与视频整理 · 2026-09-13

先退出旧版，再运行 [新版抱一.exe](D:/8.Project/0_0_维护/抱一/release/0.8.0-video-import-preview-20260913/win-unpacked/抱一.exe)。请保留整个 `win-unpacked` 文件夹。上一版发行目录仍保留。

| 反馈 | 本次行为 |
| --- | --- |
| 批量识别结果会被重新识别覆盖 | 扫描和导入先进入独立确认窗口。支持编辑、勾选、单项或所选 Agent 复查，再确认入库；复查一项不会替换整批。 |
| 需要稍后继续整理 | 预览、选择、修改和逐项日志保存为批次；关闭窗口或重启后，从“导入确认”继续。已确认条目不会重复录入。 |
| 本地识别与 Agent 切换 | 设置和导入窗口提供开关。关闭时读取文件名、info、NFO；资料不足的条目可单独交给 Agent。 |
| 同系列多集与合集命名 | 有一致系列名和不同集数时，导入预览合成合集；手动创建合集按共同片名与集数建议名称，支持修改。里番仅显示集数。 |
| 已导入单集需要整理、刮削 | “Agent 整理”位于“创建合集”左侧，可选择同系列合并、补缺失封面、补缺失资料；先核对建议，再执行。保留已有资料和观看进度。 |
| 批量选择麻烦 | 首页和导入确认支持 Shift 连续选择。 |
| 不想看到同作者下未录入的作品 | 隐藏仅来自网站目录的占位项；已经录入但文件缺失的内容仍显示。 |
| 每次创建合集都要选目录 | 在设置保存整理根目录；创建合集直接选择“保留位置 / 移动 / 复制”。移动或复制自动进入“整理根目录 / 合集名”。 |
| 新导入内容不好分类 | 收藏分组增加“未设置”，筛选未分组作品。 |

建议先在“设置 → 扫描与识别 → 视频导入与文件整理”保存整理根目录。例如根目录设为 `E:\视频\动漫\0913整理`，合集名为 `A`，整理目标就是 `E:\视频\动漫\0913整理\A`。

整理现有作品时，进入“批量管理”，用 Shift 勾选作品，再点击“Agent 整理”。只想补封面时，取消合并和补资料选项即可。同作者、厂牌或网站播放列表不会单独作为合并依据；Agent 功能需要已配置的 AI 服务。

导入确认期间如果手动移动视频、覆盖本地资料，或修改正式库中的资料与归属，窗口会保留原批次并要求“重新检查目录”。正常的文件检查时间刷新、同批确认后的补封面不会让剩余条目误失效。
