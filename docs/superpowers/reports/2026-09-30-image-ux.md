# 图片体验优化验收 · 0.10.1

## 已交付变化
对应上一会话最后提出的五类反馈：排序选项颜色随主题；日志按模块显示、计数与清除；完整性和连载更新收为紧凑工具并保留可折叠结果；选章只改变预览；阅读器新增页边按钮、滚轮翻页、页码跳转、RTL 进度条、逐屏阅读与焦点管理。详情预览切换不写阅读进度，退出阅读器回到进入时的按钮。

过程中补修点击阅读画面后焦点仍停留在模式按钮的问题，使空格逐屏阅读正常。原有界面测试的截图目标由没有布局框的紧凑组件根节点改为真实结果面板；任务面板测试明确选择影视模块。未降低既有功能断言。
