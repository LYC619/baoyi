# 通用视频来源与海报墙交付

> **范围校正：** 用户后续指出，目标是基于现成网页的在线资料库，而非先导入 JSON 再生成海报墙。本报告的测试结论仅证明通用清单版本，不代表在线来源接入或原始整体需求完成。后续以 [在线资料库重规划](../plans/2026-10-01-online-library-replan.md) 为方向记录；指定 JAV 集成仍为明确缺口。

完成日期：2026-10-01。根据用户接受的通用方案实现；没有新增内置 JAV 来源，也没有承诺第三方站点目前可以播放或下载。

## 用户能用到什么

从“影视库 → 找视频”进入，导入来源目录后切换来源，按封面浏览作品。支持标题与编号搜索、标签与榜单筛选、来源评分排序、收藏、看过状态、个人评分和备注。点观看打开独立浏览窗口；想保留时再保存视频，下载完成后可自动加入本地影视库。

浏览、收藏和观看不会新增本地影片。下载沿用现有任务中心；取消、失败重试、应用中断恢复、只存文件、登记失败后单独重试均有验证。单部视频以影片登记，重导旁边的资料文件不会变为系列；文件丢失后换画质重下会更新可播放的文件路径。

已有 Hanime 入口保留。新来源通过用户导入的标准 JSON 目录提供，目录中的观看页与完整视频下载地址独立保存。具体格式见 [使用说明](../../video-discovery.md)。

## 如何试用

独立预览位于 `release/video-discovery-preview/`。应用版本字段仍为 0.10.1，此包用于预览，不替换正式发行目录或 `release/current.json`。

1. 双击 `启动隔离预览.cmd`，程序使用预览包里的独立资料目录。
2. 双击 `启动本机演示.cmd`，保持出现的窗口打开。
3. 在“影视库 → 找视频”导入 `demo/localhost-catalogue.json`。
4. 打开作品，尝试观看和保存。六个示例使用同一段程序生成的短视频；不访问外部站点。

本机示例每次启动会更新端口，需重新导入目录。普通 `catalogue.json` 仅展示作品结构，不含播放地址。正式使用时，导入具有真实观看入口与下载地址的目录。

## 实施与参考

参考项目的具体版本及源码证据见 [参考评估](2026-09-30-av-integration-research.md)。本次借鉴海报墙、来源评分与个人评分分开、编号搜索归一化、显示榜单出处、浏览与保存分离等设计；没有直接复制第三方脚本或扩展代码，没有兼容它们的私有导出格式。

来源与个人标记独立持久化，刷新来源不覆盖个人标记。导出来源不含个人标记，完整资料备份包含标记和新下载任务。浏览窗口不带主窗口的 Node / IPC 权限，封面使用现有缓存；主应用的网页安全策略未放宽。新旧下载任务分开执行，防止把通用来源交给旧来源解析流程。

## 当前边界

- 尚无内置 JAV 来源、自动站点搜索、榜单采集和专门的流媒体解析。
- 需要先导入目录；打开网站不会自动变成抱一的作品墙。第三方脚本的备份不能直接按本格式导入。
- 下载支持明确的完整视频文件，不拼接 HLS/DASH、不处理 DRM。网页播放仍取决于站点与 Electron 的编解码支持。
- 目录中的年份、来源评分、榜单保留在来源页；本地登记主要接收标题、简介、标签、封面、来源和文件。
- 导航限制为当前目录列出的域名，额外登录或跨域跳转可能受限。未进行外部成人站点探测，未验证风控行为。
- 各类下载队列内部串行；通用队列与旧队列可以分别运行。
