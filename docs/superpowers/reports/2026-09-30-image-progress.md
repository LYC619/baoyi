# 图片优化第一阶段：下载进度与状态

持续目标的第 1 项已完成，第 2–7 项尚未完成；当前仍使用 0.9.0 版本号开发，未覆盖正式发布包。

## 实现

- 先确认所选章节的全部页面清单，整部进度固定分母；分开显示当前章进度。
- 显示目录读取、已有页校验、连接、接收、重试、限流、保存和入库状态。
- 分别统计已确认文件字节、本轮网络接收字节、复用页数及三秒窗口接收速度；失败尝试已收到的数据计入网络流量，复用文件不计入。
- 旧任务 JSON 增量兼容，重启不自动恢复网络下载；终态速度和等待截止时间归零。
- 新增独立下载任务通知并限频刷新，不让字节流驱动整库刷新。
- 保留原图请求、逐跳 HTTPS 校验、大小限制、取消和现有原子写盘/断点补页机制。
