# 图片库批量管理与性能验证

阶段 6 已完成。支持批量分类、添加/移除/替换标签、标记已读/未读；批量操作事务化，隐藏或失效
的条目/目标分类会拒绝操作。失败不会留下部分修改，也不改动图片文件、阅读进度或连载状态。

书架每页 60 项，可选择当前页或全部筛选结果，跨页保留选择，切换筛选后清空选择。标签替换需确认。
增加独立的已读筛选与标记。搜索无结果再恢复时，分页正确回到第一页。

## 实测

| 项目 | 改动前 | 最后一次验证 |
| --- | ---: | ---: |
| 2,000 部/48,000 页，Node SQLite 查询准备次数 | 10,001 | 2 |
| 同一纯数据层基准耗时 | 111,345 ms | 126 ms |
| 列表载荷字节数 | 1,374,209 | 1,374,209 |
| Electron 500 部书架挂载条目 | 500 | 60 |
| Electron DOM 节点 | 3,215 | 731 |
| Electron 进入书架至封面加载 | 1,362 ms | 405 ms |

数据层与 Electron 使用不同 SQLite 运行时，上述两组耗时不能直接互推。均为本机合成资料测量，
不承诺真实书库固定倍数。封面已有原生懒加载；首次封面完成时的解码数随异步调度波动，没有证据
要求额外缓存或解码线程，因此本阶段没有引入它们。
