## 收尾中新发现并修复

本轮先添加失败回归、确认错误后修复：

1. 进度 update 原来只更新面板、不输出控制台，长任务裁剪后无法在控制台追踪早期事件；现在在统一事件入口同步记录，并对重复事件去重。
2. 上轮失败后的 Settings 预检可能沿用旧 progress 开放停止入口，误设置停止标志；现在停止入口必须绑定真实运行中的任务。
3. 软件扫描在其他页面取消时，Settings 使用局部停止标志会误报成功；现在使用共享停止状态，并在 await 刷新库前保存本轮结果。
4. 用户同意降级扫描后，预检提醒原来未进入任务历史；现在从首页和设置页传给共享运行器，保留 warning 事件。
5. 测试 Transition 替身未声明 name 产生 Vue 告警；修正替身并让未知 Vue 告警使测试失败，不在生产代码隐藏告警。
