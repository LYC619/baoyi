# 图片／漫画模块实施计划

**Goal:** 完成原方案中的本地相册、漫画书架与阅读器，以及哔咔搜索、选章、下载入库。

**Architecture:** `resource.kind = image` 对应一个相册或一部漫画。主进程维护扫描、章节、页、阅读位置和下载队列；渲染进程只通过明确 IPC 和按页面 ID 寻址的图片协议访问内容。照片与漫画共用导入和图库索引，漫画类型独立于顶层照片／漫画分类。

**Tech Stack:** Electron 37、Vue 3、TypeScript、Pinia、SQLite、Node 文件与压缩 API。

执行方式：按项目 AGENTS.md 在主会话串行使用 executing-plans，不派发子代理。基线为 `2b2154e`；现有分支上实施，保留用户已提交的影视改动。用户已确认原方案功能和参考图视觉，无需再次询问设计或执行方式。
