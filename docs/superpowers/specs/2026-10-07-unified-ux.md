# 统一与稳定版设计

用户已确认此方向，并要求优先关注用户体验。范围是五库的共同操作与现有流程，保留启动、存档、播放、阅读、项目入口的不同用途。

## 使用规则

1. 当前模块标签回到该库首页；切换到其他模块仍恢复上次位置。整理、确认等子流程另有明确回库入口。
2. 软件整理采用固定头尾、可滚动中间列表；任何条目都可查看。完成、失败、取消均能返回软件库，处理中不重复执行。
3. 在线来源按当前类型与隐私设置显示；普通影视不会出现 Hanime 专用入口或空库引导。
4. 软件、游戏、项目补齐多选与适用批量操作。显示选中数/当前结果数，全选仅针对当前结果，筛选变化移除不可见选择，Esc 退出；输入框内 Ctrl+A 保留文本全选。
5. 软件/游戏：分类、追加标签、归档/恢复、移出资料库。项目：分类、分组、追加标签、状态、置顶/取消、移出资料库。移出仅删索引，不删原文件，执行前显示数量与用途。
6. 批量执行锁定本轮 ID 和操作，逐项显示进度，成功与失败分别计数；失败项保留选择并展示名称与原因，可重试。公共组件承担选择与反馈，资源适配仍调用各模块已有接口。
7. 图片/视频保留既有专业批量功能；审查选择、取消、空筛选、错误反馈、窄窗可达性，修复具体发现。
8. 空筛选提供清空筛选；加载与失败不误报空库。重要操作带明确文字、键盘焦点和可读名称。

## 验收

隔离 Electron 资料库中构造长软件列表、不同影视分类、游戏/照片/项目夹具。走真实 UI 验证选择、批量修改、归档恢复、移出保留源文件、过滤后选择收敛、取消/返回、960×640 滚动与操作可达、主题、重启持久化。针对部分失败及重复提交用行为单测补充。公共自检、模块记忆、类型检查、生产构建及打包后重复关键流程。记录外部站点实时访问不在离线验收结论内。
