# 影视库实测第三轮修复 · 2026-09-19

## 本地测试入口

关闭旧版程序，再运行 `release/0.8.0-field-test-round3-20260919/win-unpacked/抱一.exe`。

**第一次启动前先备份资料库**：把 `%APPDATA%\抱一\baoyi.db` 复制一份到别处。这一版第一次启动会删掉一批「无关占位集」（见下面第一条），在真库副本上排练时删了 51 条，有文件的集一条没少；但删的是你的库，备一份总是稳妥的。

## 使用上的变化

### 没下载的集不再挡住同系列别的分部

- 之前 Agent 整理或系列下载时，播放列表里的每一条都会在库里建成「占位集」（没有文件、没看过，只是挂着来源链接），哪怕标题根本不是同一系列（作者频道的整个列表都会进来）。之后想下载别的作品，程序查到这些来源就报「已在其他作品」，同系列不同部再也建不了自己的合集。
- 现在只给程序判定为同系列（能编上号）的条目建占位集。别的作品要下载某一集时，占位集不算「已归属」，登记进来的那一刻把别人的占位让出去；有文件或看过的集不会被让出去。
- 第一次启动清一次历史遗留：只删「不是同系列、没文件、没看过、没简介没封面」的占位集。真库副本上查到 51 条这种，启动后剩 1 条（`淫妖蟲 蝕` 里那一集有简介，判定不算无关占位，留着）。

### 详情页

- 「剧情简介」页签下，正在看哪一集的简介，那一行按钮里多了「播放这一集」；顶部的「播放」也跟着切到这一集。没选集或选中的那集没文件时，还是按观看进度挑。

### 搜索

- 简体能搜到繁体，繁体也能搜到简体，日文汉字（體 / 國）顺带覆盖。库里的字段和你输入的关键词两边都归一成简体再比较；合集展开后的单集筛选也用同一套规则。
- 字表是 4105 对单字，取自 OpenCC，只做单字不做词组，够搜索用。没有新增运行时依赖。

### 影视墙

- 工具栏多了一个「卡片大小」滑块（110 到 320 像素），海报视图下拖动即时生效，松手写进设置，紧凑列表下不显示。详情页排版和整体交互没动，等设计方案。

### 统一移动

- 影视墙工具栏多了「统一移动」：把已入库的作品挪成「整理根目录 / 收藏分组 / 作品文件夹」，没分组的直接放根目录下。整理根目录用的是设置里「影视整理根目录」，没设就提示先去设。
- 选择态只动选中的，否则动当前范围里的全部作品。先出预览：每部作品标成「移动整个目录」「搬文件进新目录」「已就位」或「这次不动」并给原因，确认后才动。
- 绑定了目录的作品整个目录改名搬走（同一块盘上是瞬时的），库里所有路径、清单、排除记录和扫描指纹跟着改。跨盘不动，请用「目录管理 / 重新绑定」。只有散文件的作品走现成的物理整理流程（复制、校验、切引用、删原件），能在「整理记录」里重试和回退。
- 整目录改名这条路没有进整理日志，只在 `%APPDATA%\抱一\library-layout\` 留一份从哪搬到哪的记录；要回退就照记录反着改名再「重新绑定」。
- 真库副本上预览：82 部都可移动，0 部已就位，0 部不动，目标是 `E:\视频\动漫\260913整理`。**排练只开了预览没点「开始移动」**，真机上第一次请先挑一两部试。注意「哥布林农场」绑定的目录是整个 `E:\视频\动漫\0913整理`（里面只有它一部），会整个改名搬进 `3D\哥布林农场`。

## 建议实测顺序

1. 启动后进影视墙，找一部之前「已在其他作品」下载不了的分部，重新下载，看能不能建成自己的合集。
2. 搜索框输入「斗士」，确认「被幹鬥士 瘋狂性愛！」出现。
3. 拖卡片大小滑块，重启后确认大小保留。
4. 打开一部合集，「剧情简介」里切到第 2 集，点「播放这一集」。
5. 「统一移动」先只勾一两部作品（进选择态再点），看预览路径对不对再开始；完了到「文件与资料」确认路径已切换、能播放。
