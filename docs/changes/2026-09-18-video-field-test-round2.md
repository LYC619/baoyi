# 影视库实测第二轮修复 · 2026-09-18

## 本地测试入口

关闭旧版程序，再运行 `release/0.8.0-field-test-round2-20260918/win-unpacked/抱一.exe`。

**第一次启动前先备份资料库**：把 `%APPDATA%\抱一\baoyi.db` 复制一份到别处。这一版第一次启动会把还留在旧缓存目录里的海报搬进各自的作品目录（见下面「海报都进视频库」）。搬之前会写恢复记录，搬不动的原样保留，但多一份备份总是稳妥的。

## 使用上的变化

### 海报都进视频库

- 新刮的、手选的、下载来的海报一律写进作品目录下的 `.baoyi\artwork\`，显示时直接按路径读，不再复制一份到程序缓存目录。
- 第一次启动做一次搬家：库里还指向旧缓存目录的图按作品搬进 `E:\视频\<作品目录>\.baoyi\artwork`。本机只读查到 146 处这样的引用，其中 141 张文件还在、5 张文件已经丢了（丢了的引用不动）。作品目录里已经有同一张图时只改指向，不再复制。每一张的来源和去向记在 `%APPDATA%\抱一\artwork-migrations\`。
- 算不出作品目录的作品（库里只有链接、没有任何本地文件）继续留在缓存目录。缓存目录里没人引用、视频库里也找不到同款的图不删，只在启动日志里报个数。
- 这一步在排练里没有跑到：排练用的是临时用户目录，程序在那里认不出旧缓存目录，146 处引用原样保留、图片照常显示。所以真机第一次启动后请看一眼启动日志里「影视图片已归位」那一行，再看影视墙有没有破图。

### 详情页

- 海报区多了「从单集选」：从这部作品各集的封面 / 预览图里点一张当作品封面。选过的记为你亲手选的，重扫和补封面不会再改它。
- 「作品内容」多了「管理集数」：每一集可以改季（里番是「部」）和集号，改完一次保存。同一季里集号重复会整组拒绝并提示，一条都不改。里番填 0 表示不分部；有分部时列表和简介切换按部分段，标签显示「第 N 部 · 第 M 集」。改动同时写进作品目录的 `baoyi.json`。分部只做手动设置，不从文件名自动识别。

### 影视墙

- 「资料待补齐」角标改成具体原因：缺简介、缺封面、未经识别确认，多条用「、」连。筛选也能按这三条筛。
- 旧作品要等下一次「检查文件」、整理或下载完成后角标才会细分，在那之前仍显示「资料待补齐」。
- 搜索后自动展开的合集，清空搜索会收回；自己点开的保持展开，收起后才收回。
- 批量管理里不再出现「下一步」。
- 正文、标题、路径可以选中复制；卡片和页签壳子仍不能选。
- 任务面板里下载区固定贴底、自己滚动，最多占面板高度的 45%。

### 下载补全与 Agent 整理

- 单集先刮过、后来下载补全成合集时，标题按来源编号判断是不是同一部作品，不再靠字符串比对（之前全角空格、「＃1」都会让它对不上）。原来那一集刮的简介挪到对应的单集，不再留在作品简介里。
- 创建合集时程序算出来的建议名不再算「手改」，只有你改过名字才标；导入确认表单也只记真正改过的字段。这样之后的下载补全和重新识别还能把名字纠正回来。
- Agent 只补封面时，播放页只有横图的作品会到搜索页补竖图。收尾时作品封面不是竖图、也没被手改的，换成单集里的竖图。

## 建议实测顺序

1. 启动后看启动日志里「影视图片已归位」那一行的数字，再进影视墙看里番格有没有破图。
2. 打开一部有单集封面的作品，「从单集选」换一张，回到影视墙确认卡片换了图；再点「找海报」确认没被换回。
3. 打开一部里番合集，「管理集数」把第 3 集改成第 2 部第 1 集，保存后看列表分段和 `baoyi.json`；再把另一集改成重复的集号，确认整组被拒绝。
4. 找一部之前显示「资料待补齐」的作品点「检查文件」，看角标变成具体原因。
5. 对之前那三条 `被幹鬥士 瘋狂性愛！` 试一次下载补全，看标题是否切成系列名、原简介是否落到对应单集。离线回归只用了假页面，这一步要联网。
6. 对一部封面是横图的作品跑一次 Agent「补封面」，看封面是否换成竖图。
