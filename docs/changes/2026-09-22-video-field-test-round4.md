# 影视库实测第四轮修复 · 2026-09-22

## 本地测试入口

关闭旧版程序，再运行 `release/0.8.0-field-test-round4-20260922/win-unpacked/抱一.exe`。

**第一次启动前先备份资料库**：把 `%APPDATA%\抱一\baoyi.db` 复制一份到别处。这一版启动后第一次打开
「日志 → 整理记录」或「统一移动」时，会把两条卡住的整理记录改写成对齐后的样子（见下面第一条）；
不删任何东西，但改的是你的库，备一份总是稳妥的。

## 问题出在哪

你 9-21 晚移动那部作品（`【奈芙爾】作戰失敗…`）的过程，整理日志和 `library-layout\` 记录里都有：

1. 第一次移动时作品还没绑定目录，走「搬文件」路。目标文件夹名被截到 90 字，但视频文件名保留原样
   （232 字），拼起来 261 字，超过程序设的 240 字上限 → mp4 和封面 png 被判「目标路径过长」跳过，
   只有 info.json 和 .nomedia 两个小文件搬成功。
2. 整理流程只要有一个文件搬成功，就把作品绑到新目录、把作品路径切过去、写 baoyi.json。所以虽然报
   「部分失败」，作品已经被绑到那个长名字目录，视频还留在 `E:\视频\动漫\0913\154773`。
3. 你改短名字再移动：作品已经有绑定目录 → 走「整目录改名」路。它只改名 + 改目录**里面**的路径，
   目录外的视频一个没碰，然后如实报了「已移动整个作品目录」。
4. 那条「部分完成」的整理记录还指着已经消失的长目录：重试撞「作品已绑定另一目录」，回退找不到目标
   文件，还会挡住这部作品之后所有整理。真库里 `新 最終痴漢電車 1-3` 也在同一个坑里（9-19 被统一移动
   改名过，日志指着 `E:\视频\动漫\260913整理\…`）。

## 使用上的变化

### 统一移动（修复）

- **文件名太长自动截短**：目标路径装不下 240 字时，按文件夹同样的规矩截文件名（留扩展名、补 8 位哈希）。
  用你那个 232 字的文件名试过：进截到 90 字的作品目录后全路径 211 字，能搬。
- **视频搬不过去就整部不动**：预览时先看视频本体（缺失 / 离线 / 目录本身装不下），搬不过去整部作品
  标「这次不动」并说明原因，不再搬两个配置文件就把目录绑过去。附件有问题只是跳过。
- **整理记录随目录改名对齐**：作品目录被整目录改名（统一移动 / 合集更名）后，指着旧目录的未完成记录
  自动对齐到新目录，之前因「路径过长」没搬成的文件也按新目录重新算目标。记录里会多一条
  「作品目录已从 … 移到 …，本条记录已按新目录对齐」。
- **目录外的视频会收进来**：绑定了目录但视频在外面的作品（就是你现在这部），已就位的走「搬文件进新目录」，
  要改名的改完名再收。有未收尾的整理记录、目标又是当前目录的，顺着那条记录重试，而不是另起一次。
- **有未收尾整理记录、目标又不是当前目录的作品**：标「这次不动」，提示先去「日志 / 整理记录」处理。
  以前是绕过记录直接改名，记录就永远指着一个不存在的目录。

### 顶部「任务」改成「日志」

- 四个页签：**任务**（扫描 / 识别 / 整理进度）、**下载记录**、**整理记录**、**识别与调用**。
- 红色角标只数两样：**下载待处理 + 任务失败**。鼠标停在角标或按钮上能看到拆分，比如
  「7 个下载待处理（失败或有剩余项，可重试或移除记录）」。你截图里那个 7 就是这 7 条下载：
  `淫妖蟲 蝕` 3 条、`監獄戰艦 1-4`、`自宅警備員2 1-8` 2 条、`鬼作 1-6`，都是有剩余集没下完的。
- **下载记录**默认只列「待处理」，切「全部」看已完成的。每条已结束的记录多了「移除记录」：只删这条
  记录，文件和作品都不动，角标就不再数它。
- **整理记录**从影视墙副菜单栏和详情页「更多」里挪到这里，全库的记录一起看；详情页「文件与资料」里
  那个按钮保留（那是单部作品的）。
- **识别与调用**：当前模块的识别日志（和设置页「识别日志」页签同一份），下面是最近 20 次搜索调用记录
  （原来藏在设置页「搜索服务」里）。

### 「从链接添加」和「打开 Hanime」合并

- 工具栏只剩一个「从 Hanime 添加」。面板里的「在 Hanime 里找」开站内窗口，挑好视频后用窗口菜单
  「下载当前视频」会自动回到这个面板。隐藏里番时这个按钮禁用。

### 「导入确认」从工具栏删掉

- 扫描 / 导入目录本来就会自动弹出确认窗口。关掉窗口后如果还有没确认的条目，副菜单栏出现
  「导入待确认 N」；设置页「视频导入与文件整理」里的「打开导入确认」也还在。

## 你那部作品怎么救回来

装新版，进影视墙点「统一移动」，那部作品会标成「搬文件进新目录 · 继续上次未完成的整理（2 个文件未搬）」，
目标就是现在的短名目录。点「开始移动」，mp4 和 png 会用截短的文件名搬进去、切引用、删原件。
或者到「日志 → 整理记录」找那条「部分完成」的记录点「重试未完成项」，效果一样。
`新 最終痴漢電車 1-3` 那条记录的 3 个失败项是封面 png 源文件不在了，对齐后仍然是失败，需要你自己决定
回退还是不管；它不影响播放。

## 建议实测顺序

1. 启动后看顶栏「日志 7」，鼠标停上去看拆分；打开面板切「下载记录」，条数应该也是 7。
2. 「整理记录」页签，找到「部分完成」的那条，确认目标目录是短名目录、有「已按新目录对齐」那行。
3. 「统一移动」，先只勾这一部（进选择态再点），看预览是「继续上次未完成的整理（2 个文件未搬）」再开始；
   完了到详情页「文件与资料」确认路径和播放。
4. 「下载记录」里挑一条看完的点「移除记录」，角标应该减 1。
5. 「从 Hanime 添加」→「在 Hanime 里找」→ 站内挑一个 → 菜单「下载当前视频」，看是否回到面板。
