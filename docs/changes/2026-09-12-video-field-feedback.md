# 影视库实测反馈修复 · 2026-09-12

## 本地测试入口

关闭旧版程序，再运行 `release/0.8.0-field-feedback-20260912/win-unpacked/抱一.exe`。

## 使用上的变化

### 详情页

- 作品类型、分类和标签常驻右上角。
- 内容分为“作品内容 / 剧情简介 / 个人笔记 / 文件与资料”四个标签页；支持键盘方向键切换。
- 即使没有季号，也会显示“第 4 集”这样的集数。每集优先显示原名。
- 点击集名进入这一集的简介；简介和笔记可以切换查看整部作品或指定单集。编辑时也保存到所选范围。
- 文件夹不再作为一个视频显示。真实存在或确实缺失的未归集视频仍保留在列表中。
- “返回影视库”固定返回影视页，保留影视库当前筛选。
- 标记单集“看过”时保留文件和版本信息，避免刷新后详情区变成空白。

### 创建合集

操作顺序：**影视库 → 创建合集 → 勾选作品 → 下一步 → 核对合集名和集数 → 创建合集**。

进入面板就自动显示内容；修改名称或集数后自动重新核对。初始流程无需填写路径，也无需另点“生成预览”。

- 一集一个文件夹时，可以勾选对应条目组建合集，视频保留在原位置。
- 加入已有合集时，把目标合集和待加入的作品一并选中，然后选择“加入已有合集”。
- 想把文件也集中到同一目录，再展开“文件整理（可选）”，勾选复制并核对目标路径。
- 原名、各集简介、原文、笔记和观看进度随各集保留；原作品记录归档保存。
- 重复集数会提示并阻止执行，直接改号后可继续。完成后可从整理记录回退。

### 下载与补齐

- 从作品内补齐时，默认当前作品目录；从链接新增时，默认配置的影视库。
- 已有影片通过来源编号关联单集，文件名与网站显示名不一致也能认出。补齐列表默认只勾选缺失内容。
- 来源目录能明确确认系列名和集数时，使用实际集数排序，避免把网站列表顺序当成集号。
- 例如从 `E:\视频\系列名 4` 补齐时，预览显示更名为同级的 `E:\视频\系列名`。开始补齐时执行更名，并更新资料库中的位置；目标目录已经存在时停止并提示。
- 新下载文件按 `原剧名 - E02 480p.mp4` 命名，不再追加进入页面那一集的名称作为前缀。已有文件名保留。
- 每集分别保存原名、简介与来源；旧资源包的集号、合集标题也随已确认的关系修复。
- 资料重试会补到对应单集，并复用已下载文件。

## 建议实测顺序

1. 打开原来的单集文件夹条目，确认列表中没有“文件夹 / 文件缺失”的假视频，实际影片仍可播放。
2. 打开“下载 / 补齐内容”，检查已有集数、默认勾选和目录更名前后的位置。先核对预览，再开始下载。
3. 查看新文件是否包含原名、集数和实际画质；查看原有那一集的观看状态是否保留。
4. 标记一集“看过”后，点击两个不同集名，确认页面正常、简介分别显示；在“个人笔记”中切换整部作品和单集，核对保存范围。
5. 从影视库勾选几个分集组建合集，检查自动预览、直接改号和“加入已有合集”。
6. 从任务中心打开影视作品，再点击“返回影视库”，确认不再跳回游戏或软件。
