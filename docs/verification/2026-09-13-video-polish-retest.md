# 三项补充修复：复测步骤

先退出旧版，再运行 [抱一.exe](D:/8.Project/0_0_维护/抱一/release/0.8.0-video-polish-20260913/win-unpacked/抱一.exe)。请保留整个 `win-unpacked` 文件夹。此版本沿用已有资料库。

1. **首页横向展开**：在海报墙点「展开 N 集」。单集按合集的卡片宽度和海报比例横向排列，空间不足自动换行。卡片展示标题、集数、时长、日期或文件状态，以及观看状态；不显示标签。点某一集应进入该集的独立介绍，点「收起单集」应恢复合集视图。标签仍可在单集详情中点击并筛选。
2. **补充来源资料**：进入 `407946` 对应作品，点具体一集，再点「单集刮削」。在「剧情简介」查看「站点发布日期」「厂牌 / 作者」「片长」；站点明确提供原作发行日期时，还会显示独立的「发行日期」。旧条目需要刮削一次才能补入新字段。没有来源的本地单集，先用「更改来源」搜索并绑定。再进入另一集，确认资料按集区分。
3. **打开所在文件夹**：进入 `姉とボイン` 详情，点「打开所在文件夹」。路径指向视频文件时，应打开资源管理器并选中该文件；路径指向合集目录时，应打开该目录。此按钮不应启动播放器。

站点发布日期与原作发行日期分别保存；没有明确来源的日期保持空缺。单集资料随合集整理、移出合集、清单重新导入及资料库备份保留；来源暂时返回空字段时也会保留已有值。

其余功能可继续按 [上一版复测步骤](2026-09-12-video-feedback-retest.md) 测试。其第 2 节的标签操作以本页说明为准：在单集详情中点击标签，首页展开卡片只显示基本资料。
