# 五模块使用逻辑与同步审查 · 2026-10-07

按用户要求在主会话串行审查。范围为软件、游戏、影视、图片、项目的分类、导入、详情、模块切换、路径变化、错误反馈和数据恢复；不是对所有外部网站或所有模型服务做可用性认证。

## 发现与处理

| 问题 | 用户影响 | 处理 |
|---|---|---|
| 图片单项编辑允许照片使用漫画分类，批量编辑却拒绝 | 操作不一致，隐藏漫画分类还会隐藏照片 | 统一后端限制、去掉照片分类控件、启动清理错分关联 |
| hanime 来源登记仍接受普通分类 | 普通影视列表混入里番 | 来源绑定与数据写入约束，旧库兼容修复 |
| 项目导入只扫描，助手仅在详情手动启动 | 导入后资料不完整，助手没有参与感 | 首次自动分析与登记记录、失败保留资料、重复导入保护 |
| 图片和项目详情没有公共子页，封面操作游离 | 长页面难找功能，封面操作占空间 | 复用 DetailTabs 与封面弹窗，资料和文件工具分开 |
| 图片、项目及视频详情子页未全部记忆 | 切模块后丢失操作位置 | 与路由查询参数同步；公共键盘子页操作保留 |
| 项目分类列表写死 | 设置或修改的自定义分类不能从侧栏筛选 | 从项目分类表和已有条目汇总，同步导入与编辑 |
| 项目移动更新数据库但只通知项目库 | 关联图片和视频可能展示旧路径 | 路径变动广播至关联模块 |
| 封面保存失败也退出选择模式 | 用户以为替换已成功 | 只有保存成功才关闭窗口 |
| 图片详情切换资源复用页面时未重载 | 可能显示上一项页面或章节 | 监听资源 ID，重置选择并重新读取 |
