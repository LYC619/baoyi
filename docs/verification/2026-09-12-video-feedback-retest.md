# 新视频修复版：重测步骤

对应已确认的 [18 项问题清单](2026-09-12-new-video-feedback-audit.md)。本轮实现包括普通目录导入、单集资料和双图、合集展开、手动分组、批量操作、移除与移动。

测试版本：[抱一.exe](D:/8.Project/0_0_维护/抱一/release/0.8.0-video-feedback-20260912/win-unpacked/抱一.exe)。请先退出旧版再打开此程序，整个 `win-unpacked` 目录需要保留。它沿用原资料库；验证用的临时资料不会进入你的库。验证结果另见 [修复与验证记录](2026-09-12-video-feedback-fixes-verified.md)。

## 1. 先重新核对 NFO 样本

目录：`E:\视频\动漫\姉とボイン`。

1. 首页右上角点「导入目录」，选择该目录。没有 `baoyi.json` 时会自动扫描并入库，不用自己生成 JSON，也没有第二次“确认注册”的步骤。
2. 查看「本轮已入库」结果：新增、更新、跳过、失败分别列出。你之前已经登记的内容可能显示更新或跳过，这是正常结果。
3. 进入作品，点「检查文件」。单条视频只检查自己的文件；已明确建立的合集才会发现目录内新增的集。
4. 点作品内容中的某一集，核对其原名、简介和标签。这个样本的 NFO 有 13 个合并去重后的题材/标签；旧记录的空缺可以在检查文件时从本地资料补入。
5. 在「文件与资料」点「搜索 / 绑定来源」，或在单集简介点「更改来源」。搜索作品名，选择这一来源对应的本地单集，再点「选用并刮削」。也可以直接填 Hanime 链接或编号。
6. 绑定后再点右上角「下载 / 补齐内容」，应能读取站点集数。

这个样本的 NFO **没有程序可用的 Hanime 编号**，所以需要一次来源匹配；文件名里的其他数字不会直接当作站点编号。「按里番刮削」现在也会实际发起来源识别，不会再仅仅读取 NFO 就结束。

## 2. 核对单集资料与两种图片

目录：`E:\视频\动漫\407946`。

1. 打开作品，点具体一集，再点「单集刮削」。已有来源编号时可直接更新；没有来源则先匹配。
2. 查看影视墙/首页展开后的单集封面，以及详情页「作品内容」中的横图。单集简介中也能分别查看封面和预览图。
3. 点「编辑这一集」，改一个标签或简介，切到另一集检查其资料未受影响。单集也有「选择封面」「选择预览图」两个独立入口。
4. 回首页点「展开 N 集」，然后点击单集标签；筛选应定位到实际命中的那一集，再进入它的独立介绍。

站点图片按实际尺寸分配用途。若站方只提供一种图片，会明确回退。手动选过的作品封面会保留；要测试站点双图，使用具体单集的刮削入口。

你之前已删除的第 2 集物理文件不会凭空恢复。如果仍有它的资料记录，可以保留为待补齐，或按下一节明确移除。

## 3. 新增、移除、移出合集

- **新增本地集**：把新一集的视频及其 NFO/JSON/图片放进已绑定的合集目录，再点「检查文件」。支持 `info.json`、`info1.json` 等名称，会按标题、来源和文件关系匹配；`_720P` 等画质后缀不会妨碍匹配同名图片。
- **移除记录**：进入该集简介，点「移除 / 移出合集…」，默认保留本地文件。普通扫描和检查文件会记住这次移除，避免自动加回来。
- **删除本地内容**：在同一窗口勾选「同时将专属本地文件移入回收站」，核对列出的文件再执行。共享文件会保留。
- **移出合集**：选择「移出合集，作为独立视频」。文件位置、观看进度、该集标签及图片保留，首页出现独立条目。
- **重新加入已移除内容**：明确使用「导入目录」可重新登记仍在本地的内容；普通扫描不会将其恢复。已移出的单集仍保持独立归属，需要合并时从首页选中它和目标合集。

手动在资源管理器删除视频后，「检查文件」会标记文件缺失，并保留资料供补齐；不会隐式删除库内记录。

## 4. 合集整理与同名附件

样本：`E:\视频\动漫\寝取られファイター ヤリっちんぐ！`，以及已有目标 `E:\视频\动漫\被幹鬥士 瘋狂性愛！`。

1. 首页点「创建合集」，选中相关单集；加入已有合集时，把那个合集也选中，然后点「下一步」。
2. 选择创建新合集或加入已有合集，核对集数和名称。
3. 展开「文件整理（可选）」，勾选「同时整理文件到统一目录」。可选「复制，保留原文件」或「移动，完成校验后移除原文件」，并选择目标目录。
4. 预览会列出视频及附件的实际去向。同名 `info.json` 分开保存到 `.baoyi/originals/` 下；图片集中放在 `.baoyi/artwork/`；目录内保留一个 `.nomedia` 标记。
5. 执行后核对各集资料和文件。移动在复制、校验及资料写入完成后才移除专属原件；共享原件仍保留。
6. 在「整理记录」可以重试未完成项，或「回退本次操作」。移动回退恢复原位置，目标副本仍保留。

`baoyi.json` 保存标准化作品/单集资料；原始 `info.json`、NFO 等也会保留，二者并非互相替代。`.nomedia` 是目录标记，无需合并进 JSON。旧版已经留下的重复图片不会自动清理，新生成的资料采用统一位置。

## 5. 收藏分组、批量管理与重扫

1. 详情「文件与资料」里的分组输入框可直接改、选择已有分组或清空，无需开启整页编辑。
2. 刮削和 Agent 不再自动写收藏分组。以前自动生成的分组保留，避免误删你的整理结果；可以用批量操作清空或调整。
3. 首页点「批量管理」，选择作品后可设置分组、加/移除作品标签、批量删除。作品标签和各集独立标签分别管理。
4. 再扫一次未变化的原目录，结果应说明“已在某作品/合集，文件及资料未变化，未调用识别”。已有历史整理记录也参与判断，不必重新调用 Agent 才发现重复。

## 建议反馈方式

可按上面 1–5 的顺序重测，最后统一反馈。记录「入口、预期、实际、对应目录/集数」即可；有错误时带上完整提示和本轮扫描/整理结果。优先确认 NFO 来源匹配、407946 的双图，以及新集的移除与重扫，这三项最能覆盖之前卡住的流程。
