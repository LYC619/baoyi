# 本轮实测问题复测步骤

先退出旧版，再启动 `release/0.8.0-video-field-retest-20260913/win-unpacked/抱一.exe`，保留整个 `win-unpacked` 文件夹。新版沿用现有资料库，测试过程中没有写入正式资料库。

1. **图片位置**：正常从项目内启动时，受管影视图片存放于项目根目录的 `data/posters`。首次启动会复制并校验旧缓存、更新引用，然后清理成功迁移的旧副本。迁移恢复记录位于 `data/artwork-migrations`。手选图片的外部原件和视频目录不移动。显式指定数据目录及绿色版继续遵循各自的数据目录。
2. **日期与补齐**：分别打开原来独立导入的两集。单集作品顶部应显示已经保存的日期；点击“下载 / 补齐内容”应正常打开，同一播放列表中归属另一个作品的集数显示“已在其他作品”，不能重复勾选。原两集没有被识别为同一个视频，旧错误来自按整份播放列表判断归属。
3. **新增本地第二集**：对已有第二集目录资料的作品，将匹配的第二集视频放回同目录，点击“检查文件”，应显示文件可用。第二集文件仍在目录时打开移除窗口、勾选本地删除，预览应包含视频文件。未确认前不会删除。已经移走的文件继续显示缺失。
4. **导入记录**：通过“导入目录”导入，随后打开右上角任务中心。“影视目录导入”应保留进度和逐项结果；使用在线识别时，可在任务内展开“查看识别日志”。直接读取 NFO 或作品清单时没有在线识别对话，任务日志仍会记录本地导入结果。
5. **任务排序**：正在执行的任务与下载队列在上方，普通任务历史随后；完成的下载位于下方“下载结果”，默认折叠。
6. **创建合集**：选择两集并进入下一步，默认名称应取系列标题，去除 `LEVEL：1`、`＃1` 等集数后缀。此前没有产生实际改动的失败记录不会阻挡重新预览创建。已经尝试过文件整理的未完成记录仍需重试或回退。
7. **详情布局**：点击单集简介，桌面窗口中图片位于左侧，标题、日期和简介位于右侧，标签在下方。手动切换到作品简介后，检查文件不会重置查看范围。

完整验证结果见 [本轮验证记录](2026-09-13-video-field-retest-verified.md)。
