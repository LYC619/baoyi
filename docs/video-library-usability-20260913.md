## 推荐操作

1. 升级后先做一次“扫描本地”。旧版识别缓存会补读一次新增支持的日期与制作方字段，已有观看进度和手动资料保留，后续继续跳过未变化的文件。
2. 以后往已有作品文件夹加入同系列视频，进入“作品内容”点击“检查文件”。不能确认归属的文件会给出提示，可通过“导入目录”单独识别。
3. 需要进一步补全时，进入“待处理”，点击“选择待复查作品”，再用“Agent 复查所选”。也可在“批量管理”中自行选择作品；复查串行执行，过程保存在任务日志中。
4. 在线浏览时，进入喜欢的视频页，点击窗口顶部“下载当前视频”，在抱一里确认集数、清晰度和保存位置，再点击“下载所选”。窗口首页没有当前视频时，该菜单项不可用。

普通本地识别无需配置模型。Agent 复查需要启用并配置 AI。已有的单集刮削与来源管理仍可使用。

海报沿用上一轮的存储规则：从本项目启动普通版时，受管海报保存在项目的 data/posters。此次验证使用独立测试 profile 和中性合成图片；测试没有改写正式资料库或用户视频。
