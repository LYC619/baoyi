# 抱一 0.19.1

2026-11-07。此版本包含 0.19.0 的项目便签与托管启动、资料精读、视频预览、JM 漫画摄入，并完成 18 项交互与状态修订。

## 下载与运行

[版本下载页](https://github.com/LYC619/baoyi/releases/tag/v0.19.1)。Windows x64 用户下载 `BaoYi-0.19.1-windows-x64.zip`，解压完整目录后运行 `抱一.exe`。使用标准 AppData 数据目录，免安装不等于便携数据模式；不要只复制 exe，也不要同时打开新旧版操作同一资料库。程序未进行代码签名。

旧版目录保留。应用数据库 schema 为 30，本次交互修订不再修改数据库结构。首次从更早版本升级前请在设置中备份资料库。

## 主要改动

- 项目便签独立为一个栏目；生成交接 Prompt 的按钮移到输入区域下方，结果可重新生成或返回调整范围。
- 资料详情同时显示封面与精读结果；开启分类自动精读时必须至少选择一类；阅读器复制使用原生剪贴板。
- 视频悬停显示独立 16:9 预览窗，支持时间轴、时间码、当前帧试看与多版本默认选择；列表操作统一图标，批量管理回到主工具栏。
- 音频切换模块后继续播放；底部播放器、项目运行条、最小化阅读器与归档助理按可用空间避让。
- 在线漫画统一哔咔与 JM 入口，支持 JM 榜单、搜索、编号直达、目录记忆和统一任务列表；切换代理保留预览与选章，清理暂存增加确认，补章仍锁定原作品位置。
- 网络与出站代理设置合并；个人待办移除重复展示，管理入口补全 HTTPS 并使用系统浏览器。

## 验证与边界

交互修订已通过 15 项状态/目标检查、29 项相关回归及 19 组成品场景；版本交付另核对构建、版本号、运行组件、打包内容及成品行为。真实音频、FFmpeg、剪贴板和隐私撤销参与验证；模型与漫画任务部分采用隔离合成数据。实际 JM 榜单/搜索仅验证摘要返回，不代表全部作品、账号与线路。

AI 功能需要用户配置模型服务；在线来源受网络和站点可用性影响。PDF 精读不含 OCR，视频抽帧需要可用的 FFmpeg。用户日常库升级、长期大规模使用和全部公网来源仍需实际使用反馈。

发布附件包含可运行目录 ZIP、产品源码 ZIP、SHA-256 校验表和来源/验证清单。用户资料库、阅读档案、历史会话及本机验证 profile 不属于发布内容。
