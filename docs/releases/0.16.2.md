# 0.16.2 · 软件类型设置与整理说明

2026-10-11。补上实测中缺失的软件类型修改入口，并澄清整理操作的含义。

- “重新归置”改名为“更改整理位置”。鼠标悬浮时说明：实体软件会移动整个文件夹，链接软件只移动链接入口；操作后仍属于已整理。“转为实体”和“移除链接”也增加悬浮说明。
- 每个已整理条目提供“软件类型”下拉框，可选择绿色版、安装版或待确认。在“类型待确认”筛选中可直接逐项设置；保存后条目进入对应筛选，当前筛选和搜索保留。
- 详情页“文件与启动 → 位置信息”也可以修改类型。两个入口共用保存行为，失败会恢复原值并提示原因；修改只影响类型字段，文件路径、链接和移动风险记录保持原值。
- 链接属于存放方式。通过链接管理的软件即使标为绿色版或安装版，仍出现在“链接软件”筛选中。

退出旧版后打开 `release/0.16.2/win-unpacked/抱一.exe`，保留整个目录。继续使用原 AppData 资料库及 schema v15；旧版保留原位，本地发行未签名。

继承 0.16.0–0.16.1 的目录同步、局部刷新及卸载重装检查。重装仍按“整理根 / 分类 / 软件名”放置，完成后手动同步；目标已有旧链接时先移除链接，再由软件自身安装程序安装。
