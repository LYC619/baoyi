# 0.20.5 · 全模块日常使用体验专项优化

本版保持数据库结构不变（Schema v33），围绕日常高频操作完成了 5 批共 23 项体验改进：

- **音频子模块独立与影视播放**：音频从「全部影视」海报墙与统计中独立出来，拥有专属歌单分组、标签筛选与批量管理；卡片视图支持直接展开专辑曲目、点单曲自动排入后续队列，详情页支持调整曲序；底部全局播放器补齐播放清单面板、顺序/列表循环/单曲循环/随机切换与音量滑块；影视设置支持指定默认本地播放器并接通详情主播放按钮，海报墙展开单集独立成行。
- **照片、漫画与文库阅读**：照片补齐拍摄时间排序、跨文件夹连翻与详情原路返回；漫画阅读器恢复底部全宽进度条，支持画布左右点击翻页、双击放大、上下话与合集续读及末页自动标已读；在线漫画打开作品自动收起下载弹窗，补齐 JM 编号与检查更新入口；文库分清「阅读 / 资料」详情字段，阅读器记住字号配色、目录开关与单篇 TXT 编码，补齐当前页书签、`Ctrl+F` 页内查找、PDF 纸色滤镜与 `Ctrl+滚轮` 缩放。
- **游戏与软件日常管理**：脚本与管理员方式启动游戏同步更新最近游玩与在玩状态；内置攻略阅读器支持加载游戏目录配图、内嵌查看 PDF 攻略、切换 Excel 多工作表与自动恢复阅读位置，修好安卓包重定位；软件详情新增目录/主程序重定位与多启动项下拉，共用目录下的单文件 `.exe` 整理不再误搬整个上级文件夹；软件与游戏卡片补齐右键菜单、存档备注备份、按需勾选随开修改器与忽略名单单条恢复。
- **项目工作台与个人记录**：项目详情顶部常驻可随手编辑的「当前进展与下一步」便签，顶栏提供一键打开编辑器、终端与停止运行进程，工作区脚本支持一键运行；项目关联资料提到首屏并改为搜索直接点选，原位关联本地文件一步完成；个人「技能」补齐不依赖 AI 的手动建卡与直接记练习表单，修好总览到期跳转、待办直接打钩、状态快捷备注与趋势图移出恢复最新值。
- **全局搜索、设置同栏与归档助理**：新增跨全部模块的全局搜索跳转框（顶栏放大镜、`Ctrl+Shift+K`、详情页 `Ctrl+K` 或列表页二次 `Ctrl+K`，页内按 `/` 快速聚焦），接通鼠标侧键与 `Alt+←/→` 前进后退、`Ctrl+,` 打开设置及跨模块原路返回；设置页左侧合并展示「当前模块设置 + 通用设置」，新增通用「网络代理」页签；宽屏下归档助理与主界面左右并排分栏且支持拖拽调宽，支持一键附带当前正在看的条目、折叠连续查询步骤、一键复制回复与整轮修改一键撤回。

标准目录版位于 `release/0.20.5/win-unpacked/抱一.exe`（沿用原 AppData 资料库，切换前请先正常退出旧窗口）。保留 `release/0.20.4` 与 `release/0.20.3` 作为回退版本；最新公开下载仍为 0.19.1，本机 0.20.5 成品尚未作为公开安装包附件发布。
