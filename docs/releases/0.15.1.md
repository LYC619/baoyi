# 0.15.1 · 详情、查询与布局修复

2026-10-09。承接 0.15.0 的五库统一体验，修复快速切换资源、查询尚未返回和小窗口批量操作中的问题。

## 使用变化

- 图片详情加载时显示等待状态，读取失败可重试。快速切换相册后，旧请求不能覆盖当前资源；保存、移动、移除及重扫都固定操作对象。
- 影视搜索、防抖、刷新失败期间暂停勾选和批量提交。成功恢复查询后才可操作当前结果；等待时仍可清空选择或退出批量模式。
- 项目导入只完成本地登记，不等待模型。导入后在项目助手点击“让助手了解项目”主动分析，可停止、重试，并在核对后应用资料建议。模型失败不影响导入结果，重复导入保留人工资料。
- 软件“批量管理”并入工具栏，标准小窗口释放 44 px 浏览高度；列表文字与右侧图标、启动按钮不再重叠，键盘焦点也能显示启动按钮。
- 照片分组下拉框与实际书架保持一致，损坏或无效视图偏好会安全回退；照片与漫画切换后不会保留不支持的批量操作。
- 五库零选择时收起参数表单，选中后只显示当前操作所需控件。处理中和失败结果持续可见；逐项操作只重试失败项，图片和影视仍保留原有原子更新语义。
- 游戏和影视将视图设置、低频维护操作收进菜单，支持键盘打开、Esc 关闭及焦点返回。影视本地导入入口合并，音频范围继续显示“导入音频”。图片与项目减少重复标题、数量行，增加首屏资源空间。
