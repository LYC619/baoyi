# 0.14.1 · 分类隔离、导入登记与详情交互

2026-10-07。根据实测修复图片、视频和项目库，并审查五个模块的使用逻辑与衔接。

## 使用变化

- 照片不再显示或使用漫画分类；按来源目录和标签整理。历史错分照片解除漫画分类关联。
- hanime 作品保持里番归属，修复旧记录并约束登记、编辑与重新识别。
- 图片封面通过点击左上角封面选择替换；内容、资料、文件管理拆为子页。
- 项目导入自动保存本地资料与登记记录。AI 已配置时补全新项目简介、标签并保留处理过程；失败不撤销导入，已有项目不被重复补全覆盖。
- 项目详情统一为工作区概览、项目助手、项目入口、项目资料；图片、视频和项目子页保留切换位置。
- 项目自定义分类与侧栏、编辑、导入同步；项目路径变化通知关联图片和视频刷新。

首次补全仅自动应用简介和标签。后续对话仍展示建议并由用户选择应用；助手使用已有模型配置，能够读取项目范围内的文本与 Git 状态，不执行项目脚本或修改源码。

## 运行

退出旧版后运行 `release/0.14.1/win-unpacked/抱一.exe`，保留整个目录。标准版继续使用原 AppData 资料库，旧版产物保留。当前仍使用 schema v15，分类修复通过启动兼容处理执行。
