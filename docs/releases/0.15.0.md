# 0.15.0 · 统一体验版

2026-10-08 完成交付验收（程序于 10 月 7 日生成）。本版围绕五个模块的日常操作补齐基础能力，重点是可靠返回、完整预览、清楚的选择范围和可恢复的失败反馈。

## 使用变化

- 软件库新增批量管理：当前结果全选、分类、追加标签、归档、恢复和移出资料库。选择模式下点击卡片只选择，不启动软件。
- 游戏库将原有封面选择扩展为批量管理，支持分类、标签、归档、恢复和移出；原封面补齐仍可只处理所选游戏。
- 项目库新增批量分类、分组、标签、状态、置顶/取消置顶和移出，保留原项目与入口文件。
- 三库共用选择与反馈：显示选中数/结果数；筛选后移除不可见选择；搜索结果尚未返回时锁定提交；部分失败列出名称和原因，并仅保留失败项供重试。
- 当前模块顶栏标签可回到该库首页；切换其他模块仍恢复上次页面。软件整理的返回和取消有确定的软件库出口。
- 软件整理长列表能够完整滚动，头尾操作保持可达；执行后展示移动、链接、跳过、失败数量，提供记录与撤销入口，以及完成后返回软件库。
- 软件搜索框与实际筛选条件同步；软件、游戏、图片、项目的空筛选提供清空入口，视频搜索/条件筛选也可直接清空。
- Hanime 添加入口仅在里番范围且未隐藏时显示。普通影视空库提示与全局下载空状态不再默认引导 Hanime。
- 照片批量管理不显示漫画阅读状态和漫画分类整理；图片批量整理入口增加文字，支持 Esc 退出和 Ctrl+A 选择结果。图片移动有警告时保留选择供核对。
- 视频批量保存防止重复提交和保存中退出；输入控件内的快捷键不会误关闭批量面板。公共键盘焦点有一致的可见边框。

## 操作约定

全选针对当前筛选结果；软件和游戏在结果更新期间暂缓提交。追加标签保留已有标签。移出资料库只移除收录资料，原文件保留，操作前显示数量并要求确认。进行中的批量写入完成后再离开页面。

## 运行

正常退出旧版后打开 `release/0.15.0/win-unpacked/抱一.exe`，保留整个目录。默认继续使用 AppData 资料库；本版不改变数据库版本（schema v15）。0.14.1 包保留原位。

能力矩阵、测试范围及限制见 [统一体验验收](../verification/2026-10-07-unified-ux.md)。本版源码包含前几轮未提交成果，以本地源码摘要和发布 manifest 追溯，不以旧 Git 提交号代替完整版本来源。
