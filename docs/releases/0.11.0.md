# 0.11.0 · 视频来源与整体实测版

2026-10-02。本次将当前工作区已有功能整合为标准 Windows x64 目录版，供整体实际测试。版本包含未提交的工作区成果，以发布目录的源码 ZIP 和文件摘要追溯。

## 使用变化

- 影视「找视频」支持作品海报墙、导入目录、收藏、个人评分及备注。
- 含公开 VideoObject 资料的网页可接入海报墙，按需补齐详情，支持刷新及同站分页。明确的视频文件可在主窗口播放，点击下载进入已有任务与本地登记流程。
- 普通网页浏览保留为辅助入口。未适配网页不会自动生成海报墙；B 站、Pornhub 等站点的专用解析尚未接入，普通网页窗口仍未提供通用视频下载。
- 为外部解析服务预留主进程类型接口，没有增加下载工具、运行环境或常驻服务。当前没有解析 API 配置入口。
- 整合此前图片管理、阅读体验、模块日志隔离以及资料库升级前快照保护。

## 启动与数据

先正常退出旧版，再运行 `release/0.11.0/win-unpacked/抱一.exe`，或同版本目录下的 `start.cmd`。必须保留 exe 同目录全部文件。ZIP 需要完整解压后运行，不要直接从压缩包内启动。

标准版沿用原 AppData 资料目录；首次升级前自动创建数据库快照，失败时停止启动。快照和 JSON 备份不包含原始图片、视频等媒体，媒体文件需另行保管。0.10.1 原目录保留，但升级后的资料库不保证可直接由旧版打开。

## 建议实际测试顺序

1. 检查软件、游戏、影视、图片的原有数量与资料；在设置中确认资料目录、快照和备份状态。
2. 验证软件／游戏启动、扫描和识别；外部识别服务沿用自己的配置。
3. 验证图片章节预览、继续阅读、翻页、缩放、主题及任务中心。
4. 验证本地视频详情、播放与文件管理；使用已有目录或标准演示网页测试在线收藏及下载入库。
5. 关闭重启，检查收藏、进度、任务和设置是否保留。反馈问题时带上模块、操作步骤和版本号 0.11.0。

## 验证边界

自动验收使用独立临时资料库和合成媒体，不打开真实用户资料库，不重新下载真实账号内容。具体通过项目及证据记录在发布目录 `verification.json`。本地发行未签名。

本轮通过：发行配置 5 项、核心自检 634 项、任务操作 20 项、来源解析 11 项、下载工作流 12 项、网页来源 8 项，以及资料库升级和任务中心检查。类型检查与生产构建成功，包内 66 个编译文件与构建结果逐字节一致。

最终 exe 验收通过：基础启动 16 项、本地影视 8 项、在线来源 6 组、导入目录 10 项、普通网页浏览 5 项，以及图片体验 5 组、真实旧库升级及快照界面流程。修正两处旧界面测试在路由初始化前跳转的问题，随后在同一产物上通过。未对真实账号网站可用性作保证。
