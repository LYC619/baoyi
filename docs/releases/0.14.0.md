# 0.14.0 · 实测修复与项目助手

2026-10-06。接续上午的项目库，完成本轮游戏、视频、图片与项目实测反馈。

## 游戏与分类

游戏详情中保存的新分类会登记到共享分类表；打开设置时补齐已有条目中的历史分类。设置的分类数量与操作后刷新按当前模块取值，项目也有分类、标签管理入口。

## 视频与音频

- 具有课程名称和不重复课程序号的目录按一部合集导入，保留每讲标题并按数字排序。已按用户目录中的 1–14 讲命名验证；普通编号电影不强制合并，混合音视频保持独立归属。
- 手动导入可以重新加入曾移除的作品。预览期间保留移除记录，确认后才恢复；自动扫描仍尊重移除记录。
- “创建合集”进入“批量管理”后显示。
- 侧栏增加“其他”和“音频”类型，类型与自定义分类独立，可在详情编辑。课程自动归入“其他”，音频文件自动归入“音频”。
- 音频按专辑或目录显示曲目、标题、时长，提供播放/暂停、进度、音量、上一曲/下一曲及自动接续；播放时读取演奏者、专辑、采样率等实际标签。支持识别 MP3、FLAC、WAV、M4A 等格式，内置播放能力取决于 Chromium 编解码支持，不支持时可从详情使用系统播放器。

## 图片与照片

详情页增加“设置封面”按钮，可从现有图片页选封面。照片库开放分类筛选与管理。详情与阅读器自动读取可用的拍摄时间、相机、镜头、曝光、光圈、ISO、焦距等信息；没有 EXIF 时仅显示真实图像规格，不补造数据。

## 项目工作台

项目详情增加“工作区概览”和“项目助手”。概览显示目录内容、package.json 脚本和独立 Git 仓库状态。助手复用全局 AI 配置，可读取项目内文本、解释用途和入口、分析状态并提出简介、分类、标签等资料建议。建议展示修改前后内容，点击“应用资料建议”才写入资料库；过期建议要求重新分析。

会话支持连续追问、新对话、历史切换、工具过程查看、停止与重启恢复。项目设置包含调用轮数、历史消息数量、默认导入来源与状态，重复导入保留已有状态。文件读取限制在项目范围，排除凭据和依赖目录。此版助手用于理解与管理项目，不执行任意命令或修改源码；开发与文稿编辑继续使用已有外部入口。

交互参考 [Guichu](https://github.com/XVSHIFU/guichu)、[uTools Project Launch](https://github.com/Wwyxa/utools-project-launch) 与 [PI Desktop](https://github.com/vastsa/pi-desktop)，接入抱一现有 Agent，不另建宿主系统。

## 数据、验证与运行

数据库升级为 schema v15，新增媒体类型与项目会话备份，兼容没有这些字段的旧版备份。真实课程目录只读核对；导入、播放、修改、移动和恢复验证均使用隔离资料库与合成文件。项目助手通过本地模拟模型服务验证实际 HTTP 请求、工具调用、多轮历史和建议应用，未调用用户的真实模型服务。

类型检查、634 项公共自检、12 项本轮专项、15 项视频导入、13 项项目基础、75 项备份和 5 项打包配置回归全部通过。打包程序完成本轮 6 组与原项目 9 组界面验收，76 个编译文件逐一比对一致。

回归结果与打包校验保存在 `release/0.14.0/verification.json`、`manifest.json`；界面证据在 `output/retest-20261006/`，原项目移动回归在 `output/project-verification/`。

退出旧版后启动 `release/0.14.0/win-unpacked/抱一.exe`。需保留整个 `win-unpacked` 目录；本次标准目录版继续使用原 AppData 资料库，0.13.0 与 0.12.1 原位保留。初次升级前会按现有机制创建数据库快照。
