# 0.10.1 · 图片体验与日志隔离

2026-09-30。基于 0.10.0 的体验修复，不改变资料库结构。

## 使用变化
- 修正深色主题下排序下拉菜单的浅色底、浅色字问题，原生选项跟随深浅主题。
- 顶栏日志跟随当前模块，任务、下载列表与角标统一范围。图片只显示图片下载/修复/更新，影视下载不再混入；清除历史只清当前模块，识别搜索调用也按模块过滤。
- 文件检查、连载更新收为紧凑按钮。点击执行后展开结果，可以收起和再次展开；修复与更新状态继续保留。
- 章节按钮只切换下方预览。“上次阅读”与当前选中章分别标示；点击缩略图或“阅读本章”才打开阅读器。浏览章节不改变阅读进度。
- 阅读器增加左右页边按钮、页码跳转和阅读模式文字。适屏时滚轮翻页，放大后滚轮移动图片；连续模式用滚轮或空格逐屏向下阅读。支持 RTL 翻页与进度条方向、F 全屏、+/− 缩放、0 重置、Esc 返回。完整操作提示在阅读设置中。
- 阅读器限制键盘焦点在当前窗口，退出后回到之前的入口。拖动不误翻页，滚轮翻页节流。

## 启动
正常退出旧版本，再运行 `release/0.10.1/win-unpacked/抱一.exe`，保留 exe 同目录全部文件。
标准目录版继续使用原 AppData 资料库；0.10.0 目录保留。开发验证只使用临时资料库与合成图片，没有重新下载真实账号内容。
