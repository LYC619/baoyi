# 0.20.4 · 全库流转闭环、全局视觉统一与自然中文润色

本版在不改动数据库结构（保持 Schema v33）与用户资料库的前提下，完成体验流转、视觉一致性、自然中文文案与巨石模块拆解：

- **跨库流转与交互闭环**：软件、游戏、影视/音乐、画廊/漫画、文库与项目六大首页统一支持文件与目录拖拽入库（含单绿色软件目录直扫、单影音文件直拖带入同名字幕封面并保护同目录其他文件）；五大媒体详情页新增「所属项目与个人沉淀」反向关联面板，支持就地搜索绑定与一键带上下文唤起归档助理；全应用确认弹窗统一升级为原生 `<dialog>` 模态框，顶部提示升级为顶层 Popover。
- **视觉统一与自然中文**：收归 `variables.scss` 全局色彩/字号/细线令牌，消除工作区模块的青色强调色与暖黄浅色覆盖，对齐首屏底色防闪白，隔离文库阅读器四套纸色并恢复 PDF 跨页连续拖选；全应用界面与报错提示完成自然中文洗稿，清退底层工程黑话与翻译腔，补齐中文输入法选词守卫与无反馈角落提示。
- **组件与通信入口拆解**：按域拆分主进程通信入口与六大千行级核心页面，收敛根目录文档与历史归档，自动同步 [architecture-and-ipc.md](../architecture-and-ipc.md)（495 条 IPC 通道）。

标准目录版位于 `release/0.20.4/win-unpacked/抱一.exe`（沿用原 AppData 资料库，切换前请先正常退出旧窗口）。保留 `release/0.20.3` 与 `release/0.20.2` 作为回退版本；最新公开下载仍为 0.19.1，本机 0.20.4 成品尚未作为公开附件发布。
