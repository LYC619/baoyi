# 抱一 0.10.0

2026-09-30，Windows x64 标准目录版。完成图片工作流七项优化。

## 启动与升级

程序：`release/0.10.0/win-unpacked/抱一.exe`。保留整个 `win-unpacked` 目录，不要只复制 exe。
先正常退出旧程序，再启动新版；默认沿用 `%APPDATA%\抱一`，未搬迁或重置真实资料库。
本地包没有数字签名，Windows 可能显示发布者未知；不需要为本次升级修改系统安全设置。

首次读取旧库时先创建一致性数据库快照，再升级至结构 12。快照失败会停止启动并显示原因。
相同程序版本和资料库结构再次启动时不重复生成升级快照。实际路径与记录可在设置的数据管理页查看。
`release/0.9.0`、历史归档及原 `output/pica-network-verification` 包保留原位。
不要同时用新旧程序写同一个资料库，也不要直接用旧版打开已升级的库。

## 七项改进

1. 整部与当前章节分别计数；显示真实已存字节、接收字节、速度，以及连接、重试、限流等状态。
2. 暂停、继续与队列排序持久化；默认页级并发 2，可选 1–3；遇 429 降到串行并尊重退避时间。
3. 展示实际尺寸、格式、文件大小；只读完整性检查；仅修复缺失或损坏页，正常页和手改资料保留。
4. 手动检查连载更新，按来源章节 ID 对照；只选新增章节下载，不自动改写本地标题、分类或阅读进度。
5. 阅读器支持 25%–400% 缩放、拖动、旋转、封面独立双页、作品级设置、书签与独立已读状态。
6. 批量分类、标签与已读操作使用事务；书架每页 60 项，可跨页选择与全选筛选结果；大库列表消除逐项查询。
7. 升级前自动快照、手动快照、版本与数据路径、快照列表及最近 JSON 备份信息。

正文图片仍按站点返回的原始字节保存，不额外压缩或转码。尺寸更大不代表画师上传前的母版；程序无法保证站点持有母版。

## 来源与边界

本地未提交工作区构建，基线 `136aa58905c1ff7935bd5a2445945ccf284b1a5b`，不是 Git 标签发布。
新增 Panzoom 4.6.2 与 image-size 2.0.4；包与锁文件版本一致。保留此前已有改动。
同版本目录提供源码 ZIP、逐文件 `source-files.json`、`verification.json`、`manifest.json` 和 `SHA256SUMS.txt`。
源码快照只纳入构建源码、脚本、配置、资源及发布文档，不含资料库、下载、参考仓库或过程目录。
过程证据集中在 `output/image-optimization`，阶段记录保存在 `.planning/image-optimization-20260929` 和 `docs/superpowers`。

数据库快照含本机设置，可能包含敏感配置，不应随程序分发；它和 JSON 元数据备份都不包含原始媒体文件。
快照“创建校验”是历史结果；当前状态只检查文件存在与大小，不等同于重新计算哈希。快照不自动删除。
没有来源哈希的本地文件只能做有限校验；旧清单可能缺少完整远端页目录。来源改变文件格式时修复会停止，不冒险替换。
保留原有构建弃用提示和 WASM 路径提示；本次仅交付标准目录版，未重新交付安装器或便携数据版。
