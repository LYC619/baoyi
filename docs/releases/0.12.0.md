# 0.12.0 · 四库实测优化

2026-10-03。根据 0.11.0 实测反馈统一详情、分组与卡片显示，并修复下载和路径管理问题。

## 软件与游戏

- 软件详情：简介、使用心得、文件与启动；游戏详情：简介、存档与备份、文件与封面、笔记。
- 游戏支持不分组、分类分组、扫描根目录下的一级文件夹分组。`E:\Games\1.SLG\常识改变模拟器` 会归在 `1.SLG`；卡片大小可调，显示偏好自动保存。
- 游戏侧栏增加未分类；程序缺失和磁盘离线会显示提示，详情可重新定位整个目录或更换主程序，保留条目编号、游玩时长和存档资料。
- 逸剑风云决的历史日志显示：12 轮共 62,414 tokens，反复探索引擎与存档目录，没有登记结果。本版扩大受限的可执行文件检索深度、跳过引擎依赖目录，并预留最后两轮用于登记或明确跳过；同时修正批次累计数混入单游戏日志的问题。已用离线模型响应验证预算收尾，没有付费重跑识别。

## 视频与 JAV 审查

- 普通浏览器与发现浏览器不再用弹出广告替换当前播放页。新窗口默认拦截；普通浏览器菜单可主动打开最近拦截的链接。
- 扩展 FFmpeg 的系统与软件目录检测，并增加「设置 → 搜索服务 → HLS 下载工具」重新检测、指定 `ffmpeg.exe` 和恢复自动检测入口。检测会验证程序是否能运行，缺失结果不再永久缓存。
- PotPlayer 能播放 m3u8，但将分片合成为 MP4 仍需要独立的 FFmpeg。本版没有捆绑或安装 FFmpeg；如果自动检测仍未找到，选择已有的 `ffmpeg.exe` 即可。
- 修复 AES HLS 隐式 IV 字节位置、分片缓存与播放列表不一致、取消/失败后的并发任务收尾。缓存按长度和 SHA-256 验证后再复用。
- 首页按最近发布或最早发布排序时，卡片显示发布日期；无日期时明确标注未知。

## 漫画

- 同时下载 1–4 部作品，每部 1–3 个页面请求；默认同时 3 部。下载列表可分别调整两个参数。
- 哔咔搜索、我的收藏和排行榜支持当前页多选和批量下载，一次选择目标目录。已入库或排队的作品自动跳过；补齐已有作品仍从作品详情进入。
- 书架支持分类/文件夹分组及卡片大小。分类名称可自行管理，取消本地书架和详情中的连载/完结筛选。新库预置「待整理」「喜欢的作品」；旧分类原样保留，可重命名、批量重新分类或删除分类。
- 批量整理中可创建合集、加入已有合集，合集内可调顺序、移出单册或拆分。每册原文件、章节和阅读进度保留。
- 支持批量整理移动并按分类建立文件夹；详情也可移动单部作品。同名目标不会覆盖，下载中的作品必须先停止并移除任务。跨盘采用复制、哈希核对、更新路径、回收源目录的顺序。
- 详情可只移除记录，或明确确认后将原文件夹及全部内容送入回收站。共享目录及资料根目录受到保护。
- 支持 WebP，包括历史下载中「内容是 WebP、扩展名为 JPG」的图片；仍验证文件内容是否为支持的图片格式。
- 阅读器是可拖动、缩放、最大化、收起的非模态窗口。关闭键在右上角，功能键分布在左右栏；切换到软件、游戏等模块仍保留阅读窗口。全屏适屏模式的图像不被上下工具栏遮挡。

## 运行与升级

正常退出旧版后，运行 `release/0.12.0/win-unpacked/抱一.exe`。必须保留同目录全部 DLL 和 resources；ZIP 应完整解压再运行。

标准目录版继续使用原 AppData 资料库；此次结构版本为 13，升级前自动保存资料库快照。旧发布包原位保留。快照不包含媒体原文件。

## 验证范围

服务回归覆盖核心自检 634 项、分组与路径修复、AI 预算、HLS 加密与恢复、漫画并发/暂停/续传/修复/合集/整目录移动删除、WebP、阅读状态、来源解析、备份及升级保护。界面回归覆盖四库子页与分组、游戏重新定位、漫画合集排序、收藏/榜单批量下载、浮动阅读器与全屏、网页弹窗。

测试均使用独立临时资料库、合成媒体和模拟来源响应。真实资料仅用于只读诊断，未搬动或删除用户媒体；未使用真实哔咔账号下载、未消耗付费识别额度，也未对 MissAV 的实时播放及广告脚本做在线验收。具体构建与最终打包验收以发布目录 `verification.json` 为准。

最终标准目录包通过 5 组 Electron 界面验收（四库功能、阅读器、哔咔批量下载、网页弹窗、旧库升级）。64 个编译文件与构建结果逐字节一致，原生数据库组件及 MediaInfo WASM 均在包内。服务侧合计 25 组回归通过，发行配置 5 项通过；类型检查和生产构建通过。发行未签名。
