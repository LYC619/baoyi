# 0.16.1 · 整理页刷新与卸载重装检查

2026-10-11。修复 0.16.0 实测反馈：已整理软件移除链接后会自动同步整库、等待较久，列表也缺少清晰的软件类型区分。

## 使用变化

- 移除链接、转为实体及重新归置后，只读取受影响记录；必要时只为该软件补一条待整理预览，不再扫描整个整理目录，搜索、类型筛选和列表位置持续保留。进入整理页或主动点击同步时仍读取目录变化。
- 已整理列表提供“全部 / 绿色软件 / 链接软件 / 安装版 / 类型待确认”筛选和数量。链接软件按实际存放方式归类；实体目录只有已确认便携属性时才显示绿色软件，不根据目录位置猜测安装类型。
- 孤立链接清理后仅移除成功项，失败项继续勾选；不再重新导入目录中的其他软件。
- 卸载后留下目录、主程序已消失时，列表会明确提示。相同路径重装后同步即可恢复原记录；原链接被实体文件夹替换时，同步清除旧链接状态，保留记录 ID、备注及人工资料。
- 重新归置创建的新分类立即登记，不依赖再次同步。移动安装版或未确认类型的软件时，预览和确认会提示对快捷方式、注册表及卸载路径的影响。

## 重装到整理目录

使用 `整理根 / 分类 / 软件名` 作为每个软件的安装目录。目标位置若已有旧链接，先在抱一中移除链接，再通过软件自身安装程序安装到该目录；安装完成后手动同步一次。

新装入库的软件类型可能暂时显示“类型待确认”，可按需补充识别资料。外部改名或改换主程序路径不具备可靠身份依据，本版不会猜测新的启动文件。旧记录不会因为卸载或目录缺失而自动删除。

正常退出旧版后打开 `release/0.16.1/win-unpacked/抱一.exe`，保留整个目录。沿用 AppData 资料库及 schema v15；0.16.0 保留原位。本地发行未签名。
