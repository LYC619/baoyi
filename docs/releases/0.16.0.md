# 0.16.0 · 软件整理目录管理

2026-10-11。补全软件迁入整理目录后的持续管理：已整理条目可直接查找和调整，目录分类与软件库可以同步，删除记录时清理对应链接。

## 使用变化

- 整理页增加“已整理”页签，支持搜索，显示归档条目、目录缺失和链接失效状态；可重新归置、转为实体、移除链接及打开所在文件夹。
- 进入整理页或点击“同步整理目录”时，将一级文件夹登记为分类、二级软件目录登记入库。新软件保持待识别；能唯一匹配的外部移动会更新原记录，保留备注及启动端。
- 在详情页、批量管理或已整理页修改分类前，先预览实际目标位置，确认后移动。共享目录、位置冲突或不安全的链接状态会阻止操作。
- 删除软件记录时清理关联链接并保留真实文件；其他记录仍共用链接时保留入口。孤立链接可逐项勾选清理，执行前重新核对。
- 软件同步与文件操作在主进程串行执行，删除失败项保留在选择中，方便重试。旧记录的根目录修复保留实际 EXE 位置。

## 运行与数据

正常退出旧版后打开 `release/0.16.0/win-unpacked/抱一.exe`，保留整个 `win-unpacked` 目录。标准版继续使用 AppData 资料库，数据库 schema 仍为 v15；0.15.1 及此前版本保留原位。

本版沿用标准目录版交付。源码提交、源码 ZIP 和发布文件摘要共同记录构建来源；本地包未签名。发布证据位于 `release/0.16.0/`，测试日志及截图位于 `output/release-0.16.0/`。

## 同步边界

同步只发生在进入整理页和手动点击时，不自动调用 AI。没有主程序或身份存在歧义的目录会列入报告；缺失目录不会自动删除记录或分类。仅在外部修改软件文件夹名时，缺乏可靠身份依据，不能保证自动认回原记录。

实现及回归范围见[软件整理目录验收](../verification/2026-10-11-software-library.md)。隔离测试不读取或改动真实资料库，不代表外部模型服务或大规模资源库性能已经验证。
