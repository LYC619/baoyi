# 视频来源与海报墙

产品定位更新（2026-10-02）：在线功能保持可选、轻量。已预留 [外部解析服务接口](video-resolver.md)，目前没有配置服务，不随主程序安装下载工具；此预留尚未扩展实际网站支持范围。

入口：**影视库 → 找视频 → 在线浏览**。输入支持的网页地址，点击「接入海报墙」，即可浏览作品、收藏、内置观看和下载入库，无需导入作品清单。原有海报目录在左侧继续保留。

## 在线海报墙怎么用

1. 输入包含公开 JSON-LD VideoObject 资料的 HTTP(S) 网页，点击「接入海报墙」。也支持 @graph 和 ItemList 中的视频资料。
2. 点击作品读取详情，补齐网页明确提供的视频地址。可以收藏、评分、记录备注；这些操作不会增加本地影片。
3. 点击「观看」在主界面播放明确的视频文件；播放器内可以「下载保存」，切换下载面板会停止播放。没有可内播文件时显示原因，可手动打开来源页。
4. 下载可选择仅保存或登记本地库，复用任务中心的取消、重试。网页只提供播放页或 HLS/DASH 时，不会当作完整文件下载。
5. 来源支持刷新和同站下一页，保留已缓存作品与个人标记。未适配或请求失败会保留原有资料。

本机试用见 [演示说明](../examples/online-source/README.md)，预览启动器为 `release/online-source-preview/start-preview.cmd`。本轮只验证标准资料适配及本机普通测试影片，没有站点专用适配，不保证任意网址可用。

## 普通网页浏览（辅助入口）

1. 在“网页地址”中粘贴 HTTP(S) 地址，点击“打开网页”。只输入普通域名时会补全 HTTPS；需要 HTTP 的站点请写明协议。
2. 网页在抱一的独立浏览窗口打开，菜单提供主页、后退、前进、刷新、复制网址和返回抱一。
3. 选择“更换网址”或按 Ctrl+L，可返回应用编辑当前地址。加载失败时会显示错误页面，可刷新或更换地址重试。
4. 常用地址可填写名称并点击“保存为来源”，之后从“网页来源”卡片打开；支持编辑和移除，重启应用后保留。

「打开网页」仅浏览网页，不会自动生成海报墙、创建下载任务或登记本地影片；接入作品请使用「接入海报墙」。这个通用窗口目前不处理文件下载；网站的弹出页面会在同一浏览窗口打开，部分依赖多窗口的登录流程可能不适用。

网页来源保存在应用配置中，移除它不会删除作品收藏或本地文件。当前“完整资料备份”不包含设置，因此不包含这组网址；资料目录的完整备份会保留它们。网页使用独立浏览会话，不共享主应用的权限。

## 已有海报目录怎么用

1. 点击“导入来源目录”，选择 JSON 文件。同一个来源再次导入会更新作品资料，并保留收藏、看过状态、个人评分和备注。
2. 在左侧切换来源，按作品名、编号或标签搜索；也可以按标签、榜单、来源评分或年份筛选、排序。
3. 点击“观看”会打开独立浏览窗口。只浏览、收藏和观看时，不会往本地影视库添加作品。
4. 点击“保存”，选择画质和保存位置。勾选加入本地库后，下载完成才会登记作品；也可以只保存文件。
5. 下载进度和失败重试可以在原有任务中心查看。应用关闭前未完成的任务会标为中断，需要手动重试。已经下载好的完整文件会保留。

来源里的“观看页面”和“下载文件”可以是不同地址。没有下载地址的作品仍能浏览；下载按钮会不可用。在浏览窗口中，只有当前页面能对应目录内作品时，“保存此视频”菜单才可使用。

## 目录格式

可参考 [示例目录](../examples/video-discovery/catalogue.json)。示例不连接外站，只用于查看海报墙结构；本机完整播放、下载示例见同目录的 [说明](../examples/video-discovery/README.md)。

```json
{
  "schemaVersion": 1,
  "id": "open-films",
  "name": "开放影像",
  "homeUrl": "https://example.org/",
  "entries": [{
    "id": "film-1",
    "code": "DEMO-001",
    "title": "森林纪录",
    "description": "一部纪录短片",
    "coverUrl": "https://example.org/cover.png",
    "pageUrl": "https://example.org/film/1",
    "playUrl": "https://example.org/watch/1",
    "tags": ["纪录片", "自然"],
    "year": 2024,
    "rating": { "value": 8, "scale": 10, "votes": 123 },
    "rankings": [{ "name": "编辑推荐", "position": 2, "period": "2024", "source": "开放影像编辑" }],
    "downloads": [{ "label": "720p", "url": "https://example.org/film.mp4" }]
  }]
}
```

上面的 example.org 地址是格式占位符，需要换成实际可用地址。

| 字段 | 约定 |
| --- | --- |
| `schemaVersion` | 必填，当前为 `1`。 |
| 来源 `id` | 必填，最多 48 字符；小写字母、数字、短横线或下划线。更新时保持不变。 |
| `name` / `entries` | 必填，来源名称及作品数组。最多 2,000 部作品、单个文件不超过 5 MB。 |
| 作品 `id` / `title` | 必填。作品 ID 最多 160 字符，导入时统一小写，同来源内不可重复；标题最多 240 字符。 |
| `code` | 可选，展示和搜索用编号，保留原样。 |
| `pageUrl` / `playUrl` | 可选，作品介绍页和观看入口；缺少其中一个时会使用另一个。 |
| `mediaUrl` | 可选，明确的视频文件 HTTP(S) 地址，用于主窗口内置播放；实际格式仍需 Electron 支持。 |
| `coverUrl` | 可选，海报地址。滚动到封面时请求并缓存，不需要预下载视频。 |
| `downloads` | 可选，每项有画质名称 `label` 和完整视频文件地址 `url`。地址没有文件后缀时须明确填写 `extension`，例如 `mp4`。 |
| `rating` | 来源评分，包含分值、满分和人数；与个人评分分开显示。 |
| `rankings` | 榜单资料必须填写名称和出处；可附周期与名次。 |

地址只接受 HTTP(S)，不能在地址中嵌入账号密码。作品编号只是应用中的稳定标识，不会被用来猜测站点网址。

## 保存和备份

- “导出来源目录”只导出作品资料，不包含个人收藏、评分和备注。
- 设置中的完整资料备份包含来源目录、个人标记和下载任务；视频文件需要另行保管。
- 移除来源会移除该来源的个人标记，不会删除已经保存的视频或本地作品。
- 下载任务保存入队时的作品资料，后续更新或移除来源不会改写正在下载的任务。
- 视频旁的资料文件保存标题、简介、标签、来源等，重新导入仍按单部影片处理。年份、来源评分和榜单目前保留在来源目录，不复制到本地作品字段。

## 当前范围

保留原有 Hanime 入口。海报墙可以接入标准 VideoObject 网页，也可以导入作品目录。没有新增 JAV 来源、成人站点抓取器、排行榜采集器或站点专用播放解析器。普通「打开网页」仍为辅助浏览。

目录下载支持来源明确提供的完整视频文件，不支持 HLS/DASH 分片拼接或 DRM。网页观看取决于页面自身及 Electron 的格式支持。目录专用窗口限制为目录内站点；新增的通用网页窗口允许普通 HTTP(S) 跨站跳转，但不打开本地文件或外部应用协议。

验证使用本机生成的普通测试影片，没有探测成人站点；不能据此保证某个外部站点可用或不会触发风控。
