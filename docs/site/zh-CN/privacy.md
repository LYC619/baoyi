# 隐私与数据

抱一把资料库保存在本机。部分可选功能会访问你配置的服务商或打开的在线来源；本地保存不代表每个功能都离线运行。

## 留在本机的内容

SQLite 资料库、笔记、阅读进度、设置和操作记录存放在应用的数据目录。关联源文件通常留在原处，除非你通过相应流程明确导入、移动、下载或移除文件。准确位置以程序中的数据目录入口为准。

设置中受密钥库支持的 API Key 使用系统加密。复制到其他电脑或 Windows 账户后，原凭据可能无法解密，需要重新填写。不要把完整日常资料库当作问题附件或演示样本发送。

## 哪些操作会发送信息

| 功能 | 接收方与内容 |
| --- | --- |
| AI 识别和归档助理 | 已配置的模型服务接收任务所需提示和上下文，可能包含文件元数据或选定文件正文 |
| 联网搜索与元数据 | 已选搜索或元数据服务接收查询词和请求信息 |
| 在线影音来源 | 相应来源接收网络请求、已配置的账户信息及常规连接信息 |
| 外部链接 | 打开的网站接收正常浏览器请求 |

使用前查看服务商自己的隐私约定。未经许可，不要把保密文件交给远程模型。功能和模型兼容时，可以配置本地部署的模型服务。模型回答与分类可能出错，重要改动需人工检查。

## 产品官网

官网没有应用分析脚本、广告脚本或账户系统，字体与素材不依赖外部字体服务。GitHub Pages 或你选择的其他主机仍可能按其规则处理连接日志。点击 GitHub 链接后将进入 GitHub。

## 反馈和清理

提交问题前，从截图和日志中移除密钥、账户令牌、私人路径和正文，尽量用虚构样例复现。安全问题请参照 [SECURITY.md](https://github.com/LYC619/baoyi/blob/main/SECURITY.md)。

清理本地信息时使用应用中明确区分的库记录、文件和数据管理操作。移除库条目不一定删除源文件；删除或卸载程序也不一定清除数据目录。
