# 开始使用抱一

抱一是管理本地文件、项目和个人记录的 Windows 桌面工作区。先从一个小文件夹开始，熟悉以后再逐步加入更多内容。

## 安装与首次启动

1. 打开 [GitHub Releases](https://github.com/LYC619/baoyi/releases)，阅读所下载版本的说明。源码进度可能领先于公开安装包。
2. 将完整压缩包解压到可写目录。程序、运行库和 resources 必须一起保留，不能只搬走 `抱一.exe`。
3. 启动程序，在欢迎页选择简体中文、English 或跟随系统。以后也可在「设置 → 外观 → 界面语言」修改。
4. 选择软件扫描目录。扫描只读取图标和资料，不移动文件。AI 配置可以跳过，以后再填。

已有资料库仍从原来的位置打开。切换语言不会改文件名、笔记、标签和分类；卡片标题优先显示中文名还是原名，是另一项设置。

## 找到常用入口

顶栏可切换个人、项目、软件、游戏、影视、图片和文库，各模块会记住上次所在位置。设置页同时提供当前模块设置与通用设置。

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+Shift+K` | 全局搜索 |
| `Ctrl+K` 或 `/` | 聚焦页内搜索；没有页内搜索时可进入全局搜索 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+J` | 展开或收起归档助理 |
| `Alt+←` / `Alt+→` | 返回 / 前进 |

## 导入与日常使用

**软件和游戏。** 在设置中添加扫描目录，检查识别结果后确认入库。详情里可以设置默认启动入口、关联攻略和其他文件，以及管理可用的存档备份。扫描和移动整理是不同操作。

**文库。** 从文库入口导入文件或文件夹，也可拖入支持的文件；检查预览后再确认。支持 PDF、Markdown、TXT 阅读、书签、摘录和关联项目或个人记录。Office 和 EPUB 交给外部程序打开；PDF 阅读不包含 OCR。

**图片和漫画。** 导入相册、作品文件夹或支持的归档包。阅读器提供缩放、书签和进度，照片详情可展示文件中已有的 EXIF。在线来源需要相应权限和网络条件。

**影视和音频。** 扫描本地影音，或使用已支持的在线来源。下载前检查保存目录和预览。音频有独立库视图与底部播放栏；部分元数据服务和画面抽帧需要配置 API Key 或 FFmpeg。

**项目。** 登记项目目录，添加常用文件、编辑器、终端和命令。在便签中记录当前情况与下一步。命令会以你的账户权限在本机执行，运行前先检查内容。

**个人。** 记录技能与实践、背包费用和到期、状态指标、经历及轻量待办，并按需要关联凭证和项目。

## 按需配置 AI

在「设置 → AI 配置」填写兼容的服务地址、密钥和模型，测试连接后保存。归档助理可检索收藏、阅读选定资料，并进行已支持的记录维护。文件整理先看预览，再执行；支持撤销的操作可从修改记录撤回。

使用 AI 功能时，相关上下文会发送到你选择的服务商。处理敏感资料前先阅读[隐私说明](privacy.md)。本地浏览不要求订阅 AI；第三方费用与访问权限由你自行管理。

## 备份与恢复

在「设置 → 数据管理」查看真实数据目录和备份恢复入口。标准版通常使用 `%APPDATA%\抱一`；明确标注为便携数据的版本使用程序旁的 `data`。以程序显示的位置为准。

换电脑或尝试旧版本前先备份，真实源文件另外保留副本：资料库备份不能替代所有关联文件的备份。恢复前退出所有窗口；升级快照可协助恢复，但旧程序未必能读取新版资料库。

移除条目时看清提示：「仅移除库记录」与「删除或回收本地文件」不同。真实文件移动应先预览、核对范围，检查结果后再处理恢复记录。
