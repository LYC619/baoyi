# 常见问题

先核对所安装版本的说明：源码、文档与可下载程序可能处于不同进度。

## 支持 macOS 或 Linux 吗？

目前桌面交付目标是 Windows x64。官网能在其他系统构建，不等于桌面程序已支持这些系统。抱一不提供托管个人资料库的网页版。

## 必须注册账户或配置 AI 吗？

使用本地资料库不需要抱一云账户。AI 功能需要配置兼容模型；在线来源可能需要各自的账户、密钥、权限或网络条件。

## 选了英文，为什么有些名称仍是中文？

界面语言不会翻译收藏内容。文件名、自定义分类、笔记、导入资料和模型回复保留原文。卡片标题设置可以优先使用已有英文名，但不会凭空翻译资料正文。

## 程序打不开怎么办？

完整解压程序，保留同目录运行库与资源，退出旧窗口并检查目录是否可写。按启动错误页显示的原因重试或查看数据目录。排查期间保留资料库，不要为修复运行组件而删除资料。源码环境先执行 `npm ci`；未装好 Electron 时执行 `npm run rebuild`。

## 扫描、下载或 AI 请求失败怎么办？

先读界面原因，再检查源路径、读写权限、剩余空间、模型及凭据。联网请求同时检查「设置 → 网络代理」和来源可用性。下载速度受来源和网络影响；查看任务详情后再重试。公开反馈不要附带密钥。

## 能退回旧版本吗？

保留旧程序与对应备份，先退出当前程序。旧版本未必能读取升级后的资料库，应把兼容备份恢复到独立位置，不要让多个版本同时操作日常资料库。

## 怎样反馈问题？

在 [GitHub Issues](https://github.com/LYC619/baoyi/issues) 提供程序版本、Windows 版本、界面语言、复现步骤和已去除敏感信息的报错。说明用小型虚构资料库能否复现；功能建议和翻译修正也可从该仓库提交。
