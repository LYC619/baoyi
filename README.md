# 抱一 · BaoYi

> 知止而后得。

本地资源掌控工具。管理软件、游戏、影视和图片 / 漫画，让资源可检索、可使用、可整理。

## 功能

| 模块 | 已有能力 |
|---|---|
| 软件 | 目录扫描、AI 识别、多启动端、分类标签、使用记录、目录整理 |
| 游戏 | 游戏识别与资料、启动管理、存档位置及备份 |
| 影视 | 本地扫描、作品和合集、分集资料、海报、整理预览、下载任务 |
| 图片 / 漫画 | 来源浏览、选章下载、暂停续传、完整性修复、手动追更；缩放阅读、书签、已读和批量整理 |
| 公共能力 | 本地 SQLite、设置、代理、后台任务、资料库备份恢复与升级前快照 |

AI 识别需要用户配置支持工具调用的模型服务；在线来源受账号权限、代理、网络和站点可用性影响。
第三方参考项目仅用于理解接口和设计，见相关模块文档与第三方声明。

## 开发

技术栈：Electron 37、Vue 3、TypeScript、Vite、Pinia、SQLite。

```powershell
npm install
npm run dev
npm run typecheck
npm run selfcheck
npm run verify-release-config
npm run dist:dir
```

`dist:dir` 输出到 `release/<package.json 版本>/win-unpacked/`，复用本机安装的 Electron 运行时。
依赖初始化后遇到 better-sqlite3 ABI 不匹配时运行 `npm run rebuild`。
免安装分发与便携数据模式并不是同一回事，其他打包命令及数据差异见[发布约定](docs/releases/README.md)。

## 目录

| 目录 | 用途 |
|---|---|
| `electron/` | 主进程、IPC、软件 / 游戏 / 影视 / 图片模块和公共服务 |
| `src/` | 页面、组件、状态、类型和样式 |
| `scripts/` | 构建辅助、回归验证、诊断及数据库迁移工具 |
| `resources/` | 图标、存档索引等打包资源 |
| `release/` | 当前可运行版本及历史发布包归档 |
| `docs/` | 发布说明、设计、验证报告与历史过程文档 |
| `doc/` | 仍被脚本引用的 Hanime 接口笔记及 fixture 位置 |
| `output/` | 当前验证证据；旧测试产物在 `output/archive/` |
| `.planning/` | 分任务保存的执行记录，不作为最新发布说明 |
| `archive/` | 本地旧压缩包、探针等归档，可能含私有数据，不提交 |
| `.recover/`、`.tmp-split/` | 恢复快照及尚有未提交内容的历史工作树，保留原位 |
| `参考/`、`reference/` | 本地第三方参考资料，不随程序分发 |

## 数据安全

标准目录版默认使用 `%APPDATA%\抱一\`；绿色 / 便携数据版使用 exe 同级的 `data/`。
实际位置以应用设置中的“打开数据目录”为准，显式测试启动参数也可能指定独立目录。

资料库、账号配置、下载内容、项目根目录的 `data/` 和旧版本中的数据库快照都不属于普通构建缓存。
不要在多个版本间同时操作同一资料库；尝试旧版前先备份，新版数据库未必兼容旧版程序。
历史归档只用于本机追溯，不能直接当干净安装包发给别人。
